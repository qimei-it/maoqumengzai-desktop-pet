# 毛趣萌仔与毛趣映画的面板样式统一

确认日期：2026-11-09（Asia/Shanghai）。用户要求：桌宠形象保持独立，面板按照“毛趣映画”小程序前端的样式实现，形成统一的产品观感。本事项在继续下一项 P0 前处理，不改变既定功能或收费边界。

## 视觉来源

小程序前端 `maoquyinghua-frontend` 中的以下文件作为依据：

- `src/styles/tokens.css`：颜色、字阶、间距、圆角、材质、动效、默认/万圣/圣诞主题的单一事实源。
- `src/styles/patterns.css`：卡片、状态块、按钮、双按钮行和分段控件等复用模式。
- `docs/design/tokens.md`：主题可变/不变、语义 token 与组件使用规则。

本轮已完整读取上述规范与样式，只读取小程序仓库，未修改其代码。实际来源 SHA-256 和映射信息记录在 [source.json](source.json)。尚未与小程序真机截图逐像素对照，不将代码映射表述为双端渲染完全相同。

## 统一规则

| 项目 | 桌面采用的规则 |
| --- | --- |
| 默认品牌色 | 珊瑚色 `--color-brand`，品牌文字使用 `--color-brand-ink` |
| 页面/面板 | 暖米白 `--color-canvas`，白色表面 `--color-surface`，主题分隔线 `--color-line` |
| 文字 | 小程序统一的黑色正文 `--color-ink` 与灰色辅助文字 `--color-muted` |
| 字体与间距 | 使用同名语义 token，按桌面实际阅读尺寸与窗口空间布局 |
| 圆角 | 面板使用 `--radius-sheet`，交互行使用 `--radius-control` |
| 文字操作按钮 | 所有面板统一使用 `settings-button`：确认/打开/添加加 `primary` 主题实底，取消与辅助操作使用默认填充；28px 高、12px/600 文案、`--radius-control` 圆角，禁用和危险操作使用功能语义色。番茄时钟底部的开始与重置按钮作为例外放大到 34px、14px 文案 |
| 图标按钮 | 纯图标按钮保持图标按钮形态；不再为带文字的按钮使用 `button-soft`、`button-glass` 或 `button-pair` 旧模式 |
| 下拉选择 | 统一使用 `SelectField`：原生 `select` + Lucide `ChevronDown` 14px，图标距右侧固定 8px，禁止依赖浏览器默认下拉箭头 |
| 设置项 | 左侧标题统一使用 `--font-size-body`；每个设置入口的最后一项不绘制底部分割线 |
| 状态 | 成功、警告、错误及禁用使用小程序的功能语义色 |
| 图标 | 使用 Lucide 功能性 SVG 与 Firefox Emoji 素材方案，见 [图标规范](icon-system.md) |
| 主题 | 保留 default / halloween / christmas 三套 token；文字与功能色遵守源项目主题不变规则 |
| 新功能面板 | 聊天快捷面板、文件卡片、提醒、工作台和设置继续使用同一套规范；新组件不另写裸色值或直接引用原始色板 |
| 文案层级 | 一行只表达一个信息；标题/标签/按钮下不再叠一行小字说明，解释放 tooltip 或帮助页；开发诊断台除外 |
| 动效 | 弹簧或轻微回弹缓出，60fps；打开/关闭/悬停/拖拽分别定义；尊重减少动态效果 |

文件拖入桌宠时，在角色身周展开 Filee 式圆环：中心孔取消、左半环格式转换、右半环吃掉，松手直接执行。圆环的几何/手势移植自 Filee（MIT 署名），颜色、字体、阴影与高亮改用同一套语义 token；不复制其品牌素材。文件接收后即进入旁侧置物架，拖出时按住文件本身。宠物图像和动画资源未改动。

## 平台窗口控件

面板使用同一套 `PanelHeader`：

- macOS：使用 AppKit 原生红黄绿交通灯，标题居中，不再绘制 DOM 圆点或右上角 X
- 原生按钮通过 `titleBarStyle: 'hidden'`、`trafficLightPosition` 和 `setWindowButtonVisibility(true)` 显示；固定尺寸面板调用 `setMaximizable(false)`、`setFullScreenable(false)`，绿色按钮显示系统原生置灰
- 交通灯位置由 7px 面板内边距推导并集中写在 `panelChrome`，所有面板共用，不再单独偏移
- 面板窗口的 `body` 与 `#app` 必须保持透明，只由 `.panel-surface` 绘制圆角表面；7px 外边距留给阴影，禁止在嵌套视图里回退到不透明的 `body` 背景
- 跟宠浮层（额度药丸、音乐栏、歌词、音符、音量、眼睛、气泡、提示和专注环）统一使用 `configurePetOverlay`，作为桌宠的子窗口并共用 `CanJoinAllSpaces + Managed` 行为；Mission Control / Exposé 中必须与桌宠一起缩放并保持相对位置，不得调用 `setHiddenInMissionControl(true)`
- Windows 11：右上角最小化、最大化、关闭按钮；固定尺寸面板最大化置灰
- 顶部标题栏可拖动；按钮区域不参与拖动
- 置物架、文件转换、智能问答、批量重命名、设置共用这套结构
- 所有功能面板（置物架、智能体、格式转换、打包归档、批量重命名、设置、邮件、待办等）使用普通窗口层级，不置顶、不跨空间显示：打开时到前台，切换其他应用后可被正常遮挡，系统截图（⌘⇧4）的窗口蓝框可以覆盖面板；只有桌宠与跟宠浮层置顶
- 所有功能面板在应用失焦（点击桌面或其他应用）后直接隐藏；桌宠与跟宠浮层保留
- 所有面板支持 `Command/Ctrl+W` 关闭；原生交通灯、页内关闭与快捷键统一走面板关闭逻辑，不销毁窗口
- 设置打开时临时将 macOS 激活策略切为 `regular`，进入 Dock、Command+Tab 与前台调度；关闭后恢复为无 Dock 的桌宠模式
- 设置右侧内容区不重复显示左侧已选中的分类标题

## 桌面适配

- 将源 `page` 根选择器映射为 `:root`；主题类挂在每个窗口的 documentElement，确保派生变量在正确层级重算。
- 源 `rpx` 按 375 CSS px 参考宽度换算为桌面 CSS px（1rpx → 0.5px）。面板布局按桌面工作区设计，屏幕 DPR 不再次放大字阶。
- 带文字的按钮统一使用 `settings-button` 扁平样式，不再沿用小程序式的药丸立体材质；主按钮采用同套品牌的 `--color-brand-ink` 实底，便于在任意桌面背景上稳定显示小字号白字；悬停、焦点、键盘与减少动态效果单独适配。纯图标按钮保持图标按钮形态。
- 当前文件卡片首先应用默认珊瑚主题。三套主题在本地渲染测试中逐套核对；用户设置入口及跨窗口主题状态管理留待 P1 设置实现。
- 待办清单的六个智能分类卡片使用用户提供的活泼纯色（从左到右轻微渐变），颜色仅作用于分类卡片；其余界面继续使用语义 token。
- 本轮没有读取或同步小程序用户的实际主题偏好，没有新增云端设置同步或遥测。

## 代码与维护

- [tokens.css](../../src/renderer/styles/tokens.css)：由小程序的视觉事实源生成，包含三套主题。
- [patterns.css](../../src/renderer/styles/patterns.css)：桌面按钮和交互适配。
- [FilePocket.vue](../../src/renderer/FilePocket.vue)：置物架卡片与回收区列表，使用语义变量与统一按钮模式。
- [DonutMenu.vue](../../src/renderer/DonutMenu.vue)：Filee 式十等分轮盘（等宽间隙、圆角、悬停弹出），几何由 `src/shared/donut.ts` 计算，样式只消费语义变量。

更新方式：

```sh
npm run sync:design
npm run check:design
```

同步命令默认读取同级工程中的小程序前端；其他目录可以用 `npm run sync:design -- --source <tokens.css路径>` 指定。同步由开发者主动执行；安装和运行桌面应用不依赖小程序仓库，不会在用户设备上下载样式。

构建已包含 `check:design`，检查语义颜色、禁止组件直接引用 `--p-*`、移动单位残留和未定义变量。后续调整优先修改事实源后同步，桌面特有差异留在适配层并记录原因。

## 验证口径

本轮执行：样式检查、类型检查、生产构建、84 项单元及 30 项 Electron 集成；集成检查包含三套主题颜色、固定黑色正文、12px 紧凑操作字号、文字按钮 28px 高度、等宽网格、横向溢出与底部操作可见性，并回归文件投递、实际复制、原件保护、重启置物架恢复与音乐控制栏布局。

截图和测试记录只放本机临时目录；Windows x64 与最低 macOS的渲染验收仍按支持矩阵补齐。当前图片与 PDF 基础转换已接入并沿用同一套面板与按钮样式；Office 和音视频尚未接入。
