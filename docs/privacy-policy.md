# 毛趣萌仔隐私政策

适用版本：1.0.0 及之后的首版客户端
更新日期：2026-11-17

## 一句话说明

毛趣萌仔默认只在本机运行。桌宠动画、提醒、待办、置物架、剪贴板、截图、格式转换、备份都在本地完成，不联网，也不上传。只有你自己配置了第三方服务时，客户端才会直接连接那家服务。

## 1. 保存在本机的数据

客户端把数据存放在系统的应用数据目录下（macOS 为 `~/Library/Application Support/mqmz-desktop/`，Windows 为 `%APPDATA%\mqmz-desktop\`），包括：

- 桌宠档案与生成的自定义形象素材
- 番茄钟、喝水与久坐提醒、待办的记录
- 文件置物架与「肚子里的」回收区的索引
- 剪贴板历史
- 截图保存路径设置
- 智能体会话与消息
- 邮件账户配置、邮件缓存与数据库
- 音乐歌词缓存与 AI 互动文案缓存
- 自动备份快照

这些数据不会离开你的电脑，除非你在「设置 → 数据」中主动导出或恢复。

## 2. 不会上传的内容

- 剪贴板内容、截图、置物架里的文件、转换的文件
- 番茄钟、提醒、待办等使用记录
- 邮件正文、附件、联系人与账户授权码
- API Key、令牌与凭据

客户端没有遥测、行为统计、崩溃上报或设备指纹采集。本地功能（动画、提醒、待办、置物架、剪贴板、截图、文件转换、备份）在断网时完整可用，也不会产生模型调用费用。

## 3. 会联网的场景

只有以下情况会建立网络连接，全部由你的配置或操作触发：

| 功能 | 目标服务 | 发送内容 | 触发条件 |
| --- | --- | --- | --- |
| 智能体对话 | `api.deepseek.com` | 你的问题、会话上下文、相关工具参数 | 你自己填写 DeepSeek API Key 并发送消息 |
| 图像/视频/语音生成 | `api.minimax.cn` | 提示词与参考素材 | 你自己配置 MiniMax Key 并主动生成 |
| 自定义桌宠、Seedream 出图 | `ark.cn-beijing.volces.com` | 照片与提示词 | 你自己配置火山方舟 Key 并点击生成 |
| OpenAI 订阅额度 | `api.openai.com`、`chatgpt.com` | 本机登录凭证对应的额度查询 | 你配置了本机 OpenAI 客户端登录态 |
| DeepSeek 余额 | `api.deepseek.com` | API Key | 你配置了 DeepSeek Key |
| 邮箱收件与发信 | 你填写的 IMAP / SMTP 主机（如 `imap.gmail.com`、QQ、163、126） | 账户凭据、收件与发信内容 | 你添加并启用邮箱账户 |
| 歌词匹配 | `lrclib.net` | 歌曲标题、歌手、专辑、时长 | 播放音乐且本地无歌词 |
| 封面与专辑信息 | `itunes.apple.com` | 歌曲标题与歌手 | 播放音乐且缺少封面 |
| AI 音乐互动文案 | `api.deepseek.com` | 歌曲名称、歌手、风格、阶段 | 你开启「AI 智能互动」 |
| 技能安装 | `github.com`、`codeload.github.com` 及镜像域名 | 技能包地址 | 你主动安装技能 |
| 自动更新 | 官方更新站点 | 当前版本号与架构 | 安装包启动后检查更新（源码自行构建的副本默认关闭） |

表格中的第三方服务由各自运营方提供，其数据处理适用各自的隐私政策，不由毛趣萌仔控制。

## 4. 图片与文件

- 生成自定义桌宠上传的照片只用于本次生成，保存在临时目录；保存或放弃后删除，应用异常退出后下次启动清理。
- 照片在发送给图像服务前会重新编码并去除元数据。
- 转换与打包产生的中间文件只在本机临时目录，任务结束或取消后清理。

## 5. 账号

首版不提供账号、登录或云端同步。所有功能都在本机完成，不存在与服务端关联的用户身份。后续版本若开放账号与云同步，会先更新本政策并说明同步范围。

## 6. 备份与恢复

自动备份只写入本机应用数据目录下的 `snapshots/`，保留最近 7 份；手动导出写到你在保存对话框中选择的位置。备份不包含 API Key、邮箱授权码、转换引擎二进制与运行期文件。

## 7. 删除与导出

- 在「设置 → 数据」可以导出备份、从快照恢复、打开数据目录，或删除全部本地数据。
- 删除本地数据会清除桌宠素材、聊天与邮件缓存、设置和已保存的密钥，随后重启应用；已导出的备份与下载目录中的文件不受影响。
- 卸载应用默认保留数据目录。Windows 卸载向导会询问是否同时删除本地数据；macOS 可在 DMG 中运行「卸载.command」按提示操作，或手动删除上述应用数据目录。
- 解除邮箱或 API Key 配置会清除对应的本地凭据（凭据使用系统加密存储）。

## 8. 日志

客户端不会把内容写入日志后上传。诊断信息只在本机控制台输出，仓库中的验证记录均经过脱敏，不包含真实邮件、验证码、Key 或剪贴板正文。

## 9. 政策变更

本政策随客户端版本更新。涉及新增联网行为或数据范围变化时，会在版本说明中标注并更新本文件的更新日期。
