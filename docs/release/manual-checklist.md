# 发布前人工验收清单

自动化覆盖不到、必须在本机真实操作的项目。每项记录日期、系统版本、结果与截图路径。

自动化已完成的部分见 `docs/p0-validation-progress.md`，不要在这里重复。

## 1. 桌宠窗口与拖放

| 项目 | 操作 | 期望 |
| --- | --- | --- |
| 拖出到 Finder | 把置物架里的文件拖到桌面或 Finder 窗口 | 生成真实文件副本，原文件不受影响；拖拽期间桌宠进入「浮起」姿态 |
| 拖入 | 从 Finder 拖文件到桌宠 | 轮盘展开，松手落在扇区上执行对应动作；拖出窗口外取消 |
| 物理拖动 | 用鼠标按住桌宠拖动 | 窗口跟手，不抖动、不跳位；松手后位置保存，重启仍在该位置 |
| 跨屏拖动 | 拖到另一块屏幕 | 窗口完整可见，不被裁切；松手后下次启动停留在那块屏 |
| 缩放后拖动 | 设置 → 外观调 0.8 / 1.0 / 1.2 后拖动 | 锚点仍在脚底，点击热区跟随缩放 |

## 2. 屏幕权限

| 项目 | 操作 | 期望 |
| --- | --- | --- |
| 拒绝后恢复 | 系统设置 → 隐私与安全性 → 屏幕录制里关掉本应用，重启应用后截图 | 提示需要授权并提供跳转，不静默失败；重新授权后截图恢复正常 |
| 首次授权 | 全新安装后第一次截图 | 系统弹一次授权，允许后正常出图 |

## 3. 多屏与休眠

| 项目 | 操作 | 期望 |
| --- | --- | --- |
| 外接第二块屏 | 接入 1920×1080 屏，缩放分别设为 1× 与 2× | 面板在宠物所在屏居中；轮盘不跨屏断裂 |
| 热插拔 | 运行中拔掉外接屏再插回 | 窗口自动回到可见区域，不会掉到屏幕外 |
| 合盖休眠 | 番茄钟运行中合盖 2 分钟再唤醒 | 剩余时间按真实流逝扣减，不重复触发通知 |
| 免打扰跨午夜 | 休息提醒免打扰设为 22:00–08:00，等到 0 点后 | 免打扰置灰外观正确，不弹窗；解除后恢复 |
| 免打扰结束 | 免打扰设为 22:00–08:00，等到 08:00 后 | 08:00 后第一次久坐/护眼提醒只弹一次，之后按间隔继续 |

## 4. 安装与升级

| 项目 | 操作 | 期望 |
| --- | --- | --- |
| 首次打开 | 下载 DMG，拖入「应用程序」后双击 | 按下载页提示操作后可正常打开 |
| 覆盖升级 | 装 1.0.0，再装 1.0.1 | 应用被替换，设置、待办、邮件账户与 API Key 保留 |
| 应用内升级 | 旧版本点「检查」→「下载」→「安装并退出」 | 安装程序打开，应用 2 秒后退出；装好后启动会清理下载的安装包并推出 DMG 挂载盘 |
| 未保存拦截 | 智能体输入框留一段文字，再触发安装 | 弹窗提示「智能体输入框里还有未完成的内容」，取消后保持已下载状态 |
| 卸载 | 把应用拖进废纸篓 | 用户数据目录保留；重新安装后数据仍在 |

## 6. 桌宠与数据

| 项目 | 操作 | 期望 |
| --- | --- | --- |
| 素材清理 | 新建 2 个自定义桌宠，切到其中一个，设置 → 数据 → 桌宠素材 → 清理 | 只删除未使用的形象；当前形象保留；档案列表同步 |

| 项目 | 操作 | 期望 |
