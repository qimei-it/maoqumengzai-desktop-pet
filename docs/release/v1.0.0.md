## 支持范围

| 平台 | 架构 | 最低系统 | 安装方式 |
| --- | --- | --- | --- |
| macOS | Apple Silicon（arm64） | macOS 13 Ventura | 打开 DMG，把「毛趣萌仔」拖入「应用程序」 |
| Windows | x64 | Windows 10 22H2、Windows 11 | 运行 `mqmz-1.0.0-setup.exe`，可按需更改安装目录 |

macOS Intel 与 Windows ARM 不提供构建。

## 首次打开提示

安装包首次打开会被系统拦截，下载页需要写明：

- **macOS**：双击提示「无法验证开发者」时，打开「系统设置 → 隐私与安全性」，在页面下方点「仍要打开」；或在 Finder 中按住 Control 点击应用，选择「打开」。若提示「已损坏」，执行：

  ```sh
  xattr -dr com.apple.quarantine /Applications/毛趣萌仔.app
  ```

- **Windows**：SmartScreen 提示「Windows 已保护你的电脑」时，点「更多信息」→「仍要运行」。


## 应用内更新

客户端启动 15 秒后读取 `https://mqmz.qimeistudio.com/latest.json`：

- 清单版本不高于当前版本时什么都不做。
- 有新版本时，设置 → 关于显示「发现 vX.Y.Z」，点「下载」把安装包下载到系统「下载」目录。
- 下载完成后按钮变成「安装并退出」：打开安装程序，应用 2 秒后退出。macOS 上把应用拖进「应用程序」，Windows 上跟着安装向导走。
- 下次启动时，如果版本已经不低于清单里记下的目标版本，客户端把安装包移进废纸篓，并推出 macOS 的挂载盘（`/Volumes/毛趣萌仔`）。
- 没有装成（版本没变）则安装包原样保留，可以再装一次，不会重复下载。

清单格式：

```json
{
  "version": "1.0.0",
  "releasedAt": "2026-11-18T04:56:53.522Z",
  "notes": "可选，显示在关于页",
  "assets": {
    "darwin-arm64": {
      "file": "mqmz-1.0.0-arm64.dmg",
      "size": 239319957,
      "sha256": "1992aee917f86f0d4a569d4e37baaa6d7648ac2df4e8a456728692798fe990f5"
    },
    "win32-x64": {
      "file": "mqmz-1.0.0-setup.exe",
      "size": 218001879,
      "sha256": "4ab63c80ba60fed4371be1e7e063f14cb3506fb2d4566233725694078a8f0939"
    }
  }
}
```

`file` 只能是文件名，不能是路径或外链；带 `/`、`..`、`://` 或前导点都会被拒绝。

## 发布新版本

```sh
npm run pack:mac          # 产出 dist/mqmz-<version>-arm64.dmg
npm run pack:win          # 产出 dist/mqmz-<version>-setup.exe
npm run update:manifest   # 生成 dist/latest.json（可选 --notes "发布说明"）
```

然后把 `latest.json` 和两个安装包一起覆盖上传。旧版本安装包可以保留在服务器上，`latest.json` 只指向当前版本。

## 已验证

- 打包产出 ASCII 文件名；DMG 挂载卷名为「毛趣萌仔」，与应用名一致。
- DMG 可挂载，内含应用与「应用程序」软链；`Info.plist` 版本 1.0.0。
- 打包后的应用可正常启动：启动时只创建桌宠与按需浮层，`app.getVersion()` 为 1.0.0，`app.isPackaged` 为 true，`app.getName()` 为「毛趣萌仔」，无加载错误；通过一次设置命令可拉起设置面板。
- `scripts/update-manifest.mjs` 生成的清单与两个安装包的实际大小、SHA-256 一致。
- 定向单测覆盖清单校验（路径逃逸、短哈希、缺版本）、平台选择与版本比较。
- 定向 E2E `tests/e2e/update-row.spec.ts`：设置 → 关于显示 `v1.0.0`，开发模式下更新行显示「当前版本不检查更新」且无按钮。
