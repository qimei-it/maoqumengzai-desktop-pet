## 上线与升级回归

- 2026-11-18 已部署到 `https://mqmz.qimeistudio.com/`，服务器 SHA-256 与清单一致。
- 图标统一后原地重建了 1.0.1 安装包并覆盖上传；版本号不变，更新链路未改。
- 1.0.0 客户端实测：检查到 1.0.1 → 下载 → 打开安装包并退出 → 1.0.1 启动后安装包移入废纸篓、`update-pending.json` 清除、DMG 挂载盘退出。
- 说明：本机到服务器的 HTTP/1.1 下载较慢；应用下载到 45% 后，用同一份来自服务器的安装包预置到下载目录，更新器按大小与 SHA-256 校验通过后继续。下载地址与文件完整性已单独验证。
