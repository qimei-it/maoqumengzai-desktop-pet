# 毛趣萌仔 1.0.2 下载页素材

供官网更新使用。1.0.1 的记录见 [v1.0.1.md](v1.0.1.md)。

构建日期：2026-11-19

构建环境：

- macOS 27.0.0 arm64，Electron 45.2.3，electron-builder 26.18.1（DMG）
- GitHub Actions `windows-latest`（Windows Server 2022），同版本 Electron 与 electron-builder（NSIS）

## 为什么有 1.0.2

1.0.0 与 1.0.1 的 Windows 安装包是在 macOS 上打包的，`node_modules` 里只有 `@img/sharp-darwin-arm64`，安装包内缺少 `@img/sharp-win32-x64`。Windows 上启动时主进程直接抛错：

```text
Error: Could not load the "sharp" module using the win32-x64 runtime
```

应用无法进入窗口。1.0.2 起 Windows 安装包改由 Windows 构建，并在打包前后各校验一次原生模块：缺包时构建失败，打包后裁掉其他平台的原生二进制。

## 变更

- 修复 Windows 安装包缺少 `sharp` 原生模块导致的启动崩溃；Windows 包改在 Windows 构建，新增打包前校验与打包后裁剪。
- 设置「数据」新增本地数据删除；Windows 卸载向导可选择一并删除 `%LOCALAPPDATA%\mqmz-desktop` 并清理开机启动项，DMG 内附「卸载说明.txt」与「卸载.command」。
- 待办标签支持右键重命名与删除，智能体同样支持这两项。
- 待办面板支持放大，双击标题栏铺满或恢复默认尺寸，清单与标签区按 2:1 跟随缩放。
- 无法解密的供应商密钥不再阻塞启动，可在设置中重新保存。

## 已知限制

- Windows 构建尚未接入播放器控制（`pollMusic` / `controlMusic` 仅 macOS），没有音乐条、歌词与音量浮层。
- 1.0.0、1.0.1 的 Windows 安装包因缺少 `sharp` 原生模块无法启动，不能再作为升级来源；Windows 升级回归改用同版本覆盖安装。
- 安装包未签名，Windows SmartScreen 提示属预期，macOS 首次打开需在「隐私与安全性」中允许。
