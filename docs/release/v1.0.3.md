## 1.0.3 修了什么

Windows 验收（`mqmz-win-report-20261119-161322`）发现两处真实缺陷，均已修复：

1. **复制文本没有气泡**。数据侧正常（`mqmz.clipboard.json` 会新增条目），但文本入库路径没有调用 `showToast`，只有截图与剪贴板图片会弹。现在文本入库后会提示「复制好啦，我记下来了」，受「状态气泡」开关控制。
2. **截图进不了置物架**。监听逻辑正常——手工把图片放进 `Pictures\Screenshots` 后 2 秒内入架；问题在于该目录在用户机器上不存在，而 `resolveScreenshotFolders()` 硬编码了 `Pictures\Screenshots` 与 `Videos\Captures`，`readdir` 失败时静默跳过。现在：
   - 可以在「设置 → 文件置物架 → 截图目录」自行选择保存位置，写入 `screenshotFolder` 设置；
   - 设置行改为显示目录名（`Pictures\Screenshots`），完整路径放在 tooltip，不再把两条绝对路径挤成一行被截断；
   - 目录不存在时在标签后标注「（不存在）」。
3. **置顶采样告警**。Windows 自动项读到 `GWL_EXSTYLE=0x280020`，缺 `WS_EX_TOPMOST`。桌宠显示后现在会再次声明 `setAlwaysOnTop(true)`，并在每次 `show` 时重申，避免构造参数在部分 Windows 组合下不落到窗口样式。
