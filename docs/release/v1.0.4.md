## 1.0.4 改了什么

- **AI 智能互动不再固定 DeepSeek**：跟随「默认对话模型」，并自动回退到第一个已配置 Key 的文本模型；三家都接入联网搜索：
  - DeepSeek：沿用 `/v1/tools/search` 先搜后写；
  - 火山方舟：Chat API 顶层 `web_search_options`，需在控制台开通豆包搜索或联网内容插件；
  - MiniMax：`/v1/responses` + `tools: web_search`，引用来源从 `annotations` 读取。
  带联网生成失败时自动降级为无联网重试。
- **设置「数据」重排**：数据目录显示完整路径；应用数据、可清理缓存、桌宠素材、吃掉的文件四项带说明。
- **默认模型四项**（对话 / 图像 / 视频 / 音频）补上说明。
- **音乐 AI 与 Gmail 代理**补上说明。
- **截图目录显示完整路径**，不再只显示路径末段。

## 已知限制

- Windows 构建尚未接入播放器控制（`pollMusic` / `controlMusic` 仅 macOS）。
- 安装包未签名：Windows 会提示 SmartScreen，macOS 首次打开需在「隐私与安全性」中允许。
- MiniMax 与火山方舟的联网能力需要供应商侧开通与计费，未开通时互联会报错并降级为无联网生成。
