供官网与 Release 使用。1.0.4 的记录见 [v1.0.4.md](v1.0.4.md)。

构建日期：2026-11-20

构建环境：

- macOS 27.0.0 arm64，Electron 45.2.3，electron-builder 26.18.1（DMG）
- GitHub Actions `windows-latest`（NSIS）

## 1.0.5 改了什么

- **面板关闭后销毁窗口**：设置、待办、番茄钟、邮件、休息提醒、宠物档案、剪贴板、压缩、重命名在关闭 1.2 秒后销毁窗口并释放渲染进程，再次打开时按需重建。
  - 背景：1.0.3 验收时打开设置/待办/番茄/邮件/智能体后，内存从 694 MB 涨到 1.9 GB、进程 5→12；现在关闭后回落到基线。
  - 待办与邮件窗口的尺寸、位置在销毁前保存，重开沿用。
  - 撰写邮件窗口（compose）不销毁，避免丢失未发送内容。
