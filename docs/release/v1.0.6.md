## 1.0.6 改了什么

- **智能体消息操作改为复制**：用户消息右下角的图标由「编辑并重发」换成「复制」，点击复制该条输入内容到剪贴板并显示「已复制」；编辑消息弹窗与重新发送逻辑整体移除。
- **项目空状态与懒创建会话**：点击侧栏项目行或项目行的「新建对话」只展开项目并显示右侧空状态，不再立即创建会话；在空状态发送第一条内容时才创建会话、归入该项目并按内容命名。
- **删除后回到项目空状态**：删除项目内最后一个对话后显示同一个项目空状态，不再跳转到其他对话；项目内还有其他对话时选中最近更新的一条。
