## 1.0.7 改了什么

- **修复项目工作区被误切到“要读取的目录”**：移除智能体可调用的 `workspace_set`，工作区只能由用户在项目选择或项目设置里指定；智能体不再能把用户消息里提到的目录绑定成项目根目录。
- **项目根目录固定**：属于项目的会话始终以项目目录作为 Shell 与文件工具的工作目录；加载存储时会把会话里漂移的 `workspace` 归一化回项目目录。
- **提示词明确项目上下文**：系统提示词下发项目名与固定项目根目录，并说明用户提到的其他目录只作为读取目标；读取项目外内容统一使用 `shell_run` 的绝对路径，不能修改工作区或切换目录。
