# 动效与无障碍审计

日期：2026-11-17
对应验收项：H-P9（动效与无障碍验收）

## 方法

| 手段 | 覆盖 |
| --- | --- |
| `npm run check:contrast` | 解析 `tokens.css` 三个主题的语义色，按 WCAG 2.1 计算文本/背景对比度 |
| `tests/e2e/a11y.spec.ts` | 可访问名称、`prefers-reduced-motion`、对话框焦点与 Escape |
| 现有 E2E | 键盘事件、焦点可见性、轮盘与面板交互（`prototype.spec.ts` 等） |

## 结果

### 通过

- **可访问名称**：设置、智能体、邮件、待办清单、剪贴板、宠物档案、文件转换、批量重命名、番茄时钟、喝水提醒、休息提醒、音乐控制、打包归档 13 个面板中，所有可见的按钮、链接、输入框、下拉框、文本框都有可访问名称。
- **减弱动态效果**：设置面板在 `prefers-reduced-motion: reduce` 下没有处于运行状态的动画。
- **对话框焦点**：新建桌宠对话框打开后焦点进入对话框内部，Escape 可关闭。

### 对比度

`npm run check:contrast` 覆盖三套主题的 16 组文本/背景组合，当前全部达到 WCAG AA（禁用文字按豁免只作参考）。

原本不达标的 5 组通过桌面自有配色层修正：

| 组合 | 修正前 | 修正后 | 处理 |
| --- | --- | --- | --- |
| `--color-warning` / 卡片与提示底 | 4.22 / 3.78 | 5.06 / 4.53 | `desktop-tokens.css` 改为 `#a05f1b` |
| `--color-success` / 卡片与提示底 | 4.87 / 4.28 | 5.85 / 5.15 | 改为 `#287247` |
| 品牌文字 / `--color-brand-soft` | 4.12 | 4.58 | 新增 `--color-brand-on-soft` `#a45242`，43 处标签与软按钮改用该 token |

`--color-brand-ink` 本身未改：它压在白色和画布上是 4.89，已经合格；全站 116 处文字与 12 处选中态背景保持原样。halloween 与 christmas 两个主题沿用各自的品牌墨色，本来已达标。

### 复核（2026-11-18）

`tests/e2e/a11y.spec.ts` 4 项、`npm run check:contrast`、`npm run check:design`、`npm run check:icons` 全部通过；结论与上表一致，人工项仍未验证。

## 仍需人工核验

| 项目 | 原因 |
| --- | --- |
| 半透明浮层在真实壁纸下的观感 | 对比度取决于桌面背景 |
| macOS「减弱动态效果」「提高对比度」系统开关 | 需要在真实系统设置里切换 |
| VoiceOver 朗读顺序与播报 | 无法自动判断语义 |
| 焦点环在无边框窗口内是否被裁切 | 需要肉眼 |
| 动效手感、拖拽跟手、60fps | 主观与性能 |
| 完整键盘任务、触控板操作 | 组合路径 |
