# 歌词 API 调研与样例实测

调研日期：2026-11-08（Asia/Shanghai）。

## 建议

优先使用 LRCLIB 作为技术原型的主要在线来源，AMLL 作为补充来源；两者均由桌面客户端直接请求。正式发布前确认提供方的使用条件与歌词展示、缓存范围，并补充国内不同网络的可达性测试。

歌词功能独立于 QQ 音乐、网易云音乐、Apple Music、酷狗音乐的播放控制适配。歌词缓存、人工匹配记录、时间偏移设置留在本机，不上传毛趣映画服务器。在线查词会向相应提供方发送必要的歌曲信息，需提供开关。

## 候选比较

| 来源 | 已核实能力 | 本项目判断 |
| --- | --- | --- |
| LRCLIB | HTTPS；无需用户 API Key；按歌名、歌手、专辑、时长查询；提供纯文本与逐行时间轴歌词；支持客户端应用标识 | 原型主要来源；当前五首样例均取得对应歌手、指定时长的时间轴歌词 |
| AMLL TTML API | HTTPS；公开读取接口无需鉴权；支持按歌名、歌手及部分音乐平台 ID 匹配；有 TTML 与 LRCLIB 兼容接口 | 补充来源；应严格区分原版、Remix、翻唱等录音版本 |
| LrcShare | 申请程序专用 Key；先获取 catalog/session；支持多语言歌词；人工整理曲库 | 保留候选；仍需申请 Key 并确认产品用途，当前未带 Key 实测 |
| LyricFind | 官方提供静态、逐行、逐词歌词展示及授权服务 | 如需商务歌词授权，可进一步询价；未取得凭据、未测试曲库覆盖 |

免费读取 API 的技术可用性、软件源码许可证与底层歌词内容的使用范围是不同事项；本次不将它们合并认定为已取得完整商业歌词授权。

## 实测方法与结果

通过当前开发环境发送少量公开只读 GET 请求，先搜索候选，再读取详情。不使用任何用户账户或密钥，不保存或展示歌词正文。样例是人工选取的常见歌曲，不构成总体曲库命中率或服务可用性保证。

LRCLIB 最终按 `track_name`、`artist_name`、`duration`（秒）调用 `/api/get`，避免只按歌名取首条造成版本错误：

| 歌曲 | 歌手 | 请求/返回时长（秒） | 返回记录 ID | HTTP | 时间轴歌词 |
| --- | --- | --- | --- | --- | --- |
| 晴天 | 周杰伦 | 270 / 270 | 17788 | 200 | 有 |
| 稻香 | 周杰伦 | 223 / 223 | 5708396 | 200 | 有 |
| 海阔天空 | Beyond | 320 / 320 | 3357961 | 200 | 有 |
| 孤勇者 | 陈奕迅 | 256 / 256 | 5887572 | 200 | 有 |
| Blinding Lights | The Weeknd | 200 / 200 | 390 | 200 | 有 |

AMLL 使用 `/v1/lyrics/search?musicName=...` 搜索并按返回 ID 获取详情：

| 查询 | 结果 |
| --- | --- |
| 晴天 | 命中周杰伦版本，详情返回歌词 |
| 稻香 | 仅返回周杰伦的 Remix 摇滚版，本轮不能认定为原版匹配成功 |
| 海阔天空 | 包含 Beyond 版本，详情返回歌词 |
| 孤勇者 | 包含陈奕迅版本，详情返回歌词 |
| Blinding Lights | 命中 The Weeknd 版本，详情返回歌词 |

AMLL 的 `/v1/lrclib/get/7192686136682066` 也实测返回 HTTP 200，歌曲为《晴天》，包含 `syncedLyrics`，可用于首版逐行歌词，减少 TTML 解析工作。

搜索返回的候选数量不能视为准确版本数量。LRCLIB 的同名曲也存在多个歌手、录音时长和版本，正式匹配必须结合歌手、时长、专辑与版本标签。

## 接入设计建议

1. 优先使用用户导入歌词或本机已确认的缓存。
2. 根据当前歌曲的歌名、歌手、时长、专辑建立匹配候选；保留 Live、Remix、翻唱等版本差异。
3. 在线查词开启且缓存未命中时请求 LRCLIB；无合适结果时再请求 AMLL。
4. 对低置信度结果提供人工选择和本地记忆，不直接绑定搜索第一条。
5. 缺少可靠播放进度时仅显示文本；取得进度后支持逐行高亮与手动偏移。
6. 将无匹配、纯音乐、暂时失败区分处理；无匹配不持续重试，429 尊重 `Retry-After`。
7. 切歌时废弃旧请求的显示结果，防止上一首歌词覆盖当前歌曲。
8. 统一内部数据结构与项目命名，自行编写提供方适配器；首版无需引入完整第三方歌词 UI。

LRCLIB 要求请求携带包含应用名称、版本、项目链接或联系方式的客户端标识。注册应用是可选的，桌面端使用公开 `Lrclib-App-Id`，服务器私密 API Key 不应内置客户端。具体限额以提供方当时文档为准，不写死为业务保证。

## 调研来源与局限

API Discovery 的 Orbit 搜索和接入摘要用于发现 LRCLIB 的读取/搜索接口；摘要部分参数说明落后于官方文档，本记录以官方接口文档和实际请求结果为准。未使用 Postman 私有工作区、Context Graph 或账户资源，未复用其集合或第三方实现代码。
