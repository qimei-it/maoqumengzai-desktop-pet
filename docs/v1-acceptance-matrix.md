## 3. 每次真实验证的记录模板

记录任务 ID 与细项、执行日期、应用提交、系统/架构、依赖/客户端版本、前置授权、脱敏输入说明、操作步骤、期望与实际、通过/失败/阻塞原因、证据路径和剩余事项。真实邮件、验证码、Key、截图/剪贴板正文与个人文件不提交仓库；证据使用脱敏结构与必要状态，避免通过测试记录上传本地数据。

首次离线转换测试需要明确“全新系统、未预装引擎和运行时、安装及首次使用均断网”；此前运行过在线安装后再断网不构成该项通过。
