# 图像生成

用户要求生成静态图片时，调用 `image_generate`。

## 参数

- `prompt`：必填，完整的画面描述
- `count`：1–10，默认 1；用户没要求多张时用 1
- `area`：`1K` / `2K` / `4K`，默认 `2K`
- `ratio`：`auto` / `21:9` / `16:9` / `4:3` / `1:1` / `3:4` / `9:16`，默认 `auto`
- `format`：`jpeg` / `png` / `webp`，默认 `jpeg`

## 规则

- 直接调用对应生成工具，不要委托给子 Agent。
- 如果当前消息带图片附件，工具会自动使用，不要声称工具不支持参考图。
- 只把用户的图像需求交给这个工具，不要用它生成视频或语音。
- 生成会消耗额度，工具调用前系统会请求用户确认。
- 用户没有给出明确画面时，先把需求整理成可生成的画面描述，再调用工具。
- 工具返回“参数错误”或“不支持”时，向用户说明限制并追问，不要连续盲目重试。
- 生成完成后，用简短文字说明结果，不要再重复 Markdown 图片链接。
