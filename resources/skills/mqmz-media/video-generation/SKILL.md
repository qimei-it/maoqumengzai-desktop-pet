# 视频生成

用户要求生成动态视频时，调用 `video_generate`。

## 参数

- `prompt`：必填，镜头、动作、场景和氛围描述
- `resolution`：`768P` / `2K`，默认 `768P`
- `duration`：4–15 秒，默认 5
- `ratio`：`21:9` / `16:9` / `4:3` / `1:1` / `3:4` / `9:16`，默认 `16:9`

## 规则

- 直接调用对应生成工具，不要委托给子 Agent。
- 如果当前消息带图片、视频或音频附件，工具会自动作为参考素材，不要声称工具不支持参考素材。
- 当前只支持 MiniMax-H3，不支持超过 15 秒或高于 2K。
- 生成是长任务，工具执行期间显示进度；用户停止后不要假装已经完成。
- 生成会消耗额度，工具调用前系统会请求用户确认。
- 用户要求 30 秒、4K 或其他不支持规格时，先说明限制，再给出可执行的最接近参数。
- 生成完成后，用简短文字说明结果，不要重复 Markdown 视频链接。
