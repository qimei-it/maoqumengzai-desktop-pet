# 跨境电商 Listing 生成

> 读取 Excel 商品表，自动翻译目标语言 Listing、生成 SEO Tag、输出商品主图 Prompt，写回原文件。适配 Ozon、TikTok Shop、Amazon、AliExpress 等主流跨境电商平台。

## 亮点

- **Excel 驱动** — 在熟悉的表格里填中文商品信息，AI 自动翻译生成目标语言 Listing，告别手动翻译
- **多平台适配** — 核心流程通用于 Ozon / TikTok Shop / Amazon / AliExpress / Shopee 等平台，改语言和 Tag 规则即可复用
- **三段式商品描述** — 基础信息 / 核心优势 / 使用场景+促销，结构化输出目标语言+中文对照，方便核对
- **SEO Tag 自动生成** — 根据目标平台规则生成合规标签，覆盖搜索长尾词，拒绝营销词
- **三种图片 Prompt 模式** — 自定义模版 / 参考图反推 / 竞品首图模仿，灵活选择，直接对接 Midjourney / DALL-E
- **用户可配置模版** — 图片 Prompt 模版完全自定义，适配不同品类和视觉风格
- **增量处理** — 只处理新增或修改的商品行，已生成的不重复覆盖

## 前置要求

- **Claude Code CLI**（[安装指南](https://docs.anthropic.com/en/docs/claude-code)）
- **图片分析能力**（方式2和3需要，用于分析参考图/竞品首图）
- **Web Reader MCP**（方式3需要，用于抓取竞品商品页首图）
- Python + openpyxl（用于读写 Excel）

## 使用方法

将此文件放入 Claude Code 的 commands 目录：

```
~/.claude/commands/ozon-listing.md
```

或在 Claude Code 对话中直接输入 `/ozon-listing`。

**触发关键词：** "更新了Excel"、"Excel加了几款商品"、"帮我生成Listing"

**首次使用前请配置：**
1. 目标平台和目标语言（默认 Ozon / 俄语，可改为 TikTok Shop 英语、Amazon 西班牙语等）
2. Excel 文件存放路径
3. 图片 Prompt 模版（如需使用方式1，请在 I 列填入自己的模版）

## Excel 结构

Excel 分两大区域：第1行为大标题（B1="输入"，I1="生成"），第2行为列名，第3行为规则说明，第4行起为商品数据。具体逻辑见第3行每个单元格的说明。

**请将 Excel 文件放在固定目录下，并在使用前确认文件路径。**

### 输入区（A~I，用户填写）

| 列 | 列名 | 说明 |
|---|---|---|
| A | 日期 | 用户填写 |
| B | 商品名称（中文） | 用户填写中文商品名 |
| C | 商品图 | 商品实物图片URL，方式2/3生成prompt时融入商品外观特征 |
| D | 竞品链接 | 用户填写竞品商品链接（Ozon / TikTok Shop / Amazon 等） |
| E | 采购链接 | 用户填写（1688/淘宝/拼多多等） |
| F | 商品规格 | 用户填写，如 `304不锈钢`、`7cm` |
| G | 商品卖点 | 用户填写，产品核心卖点或使用场景 |
| H | 图片生成方式 | 1=自定义模版，2=参考图反推，3=读取D列竞品链接首图生成prompt |
| I | 模版/参考图 | 用户自定义的图片prompt模版或参考图说明 |

### 生成区（J~O，Claude 输出）

| 列 | 列名 | 说明 |
|---|---|---|
| J | 商品名称（目标语言） | 将B列中文名直接翻译为目标语言商品名，保持原意不额外发挥 |
| K | 商品描述（目标语言） | 三段式（基础信息/核心优势/使用场景+促销），上方目标语言下方中文 |
| L | 商品tag（目标语言） | 根据目标平台规则生成标签，上方目标语言下方中文 |
| M | 商品规格（目标语言） | 将F列规格翻译为目标语言 |
| N | 商品卖点（目标语言） | 将G列卖点翻译为目标语言。简洁有力，用于商品主图海报。上方目标语言下方中文 |
| O | 商品图prompt | 根据H列方式和I列模版，生成包含目标语言标题/规格/卖点的图片生成prompt |

### Tag 生成规则

- 根据目标平台规则生成标签（Ozon：30个俄语标签 `#`开头；TikTok Shop：英语标签；Amazon：搜索关键词等）
- 单个标签符合平台长度限制，标签之间用空格分隔
- 禁止：品牌名、具体参数、产品全称
- 禁止营销词：新品/促销/优惠/折扣/特价/秒杀/热卖/爆款/限时等一律排除

### 商品图 Prompt 生成规则（O列）

根据 H 列的图片生成方式：

1. **方式1（自定义模版）**：用户在I列提供自己的prompt模版，将J列（目标语言标题）、M列（目标语言规格）、N列（目标语言卖点）填入模版中对应位置。模版完全由用户自定义，skill 不预设任何模版内容
2. **方式2（参考图反推）**：分析I列参考图，提取图片的视觉风格信息，结合Excel中商品的目标语言信息生成prompt。prompt包含以下几个部分：
   - **图片结构**：商品位置、标题位置、卖点标签位置、整体构图布局
   - **文字内容与样式**：标题/副标题/卖点标签的具体目标语言内容（从J/M/N列取），文字颜色、大小、样式
   - **背景**：颜色和质感描述
   - **风格**：整体视觉风格定位
   - **视觉效果**：光影方向、立体感、投影等效果描述
   - **商品卖点信息**：使用F列（规格）和G列（卖点）的目标语言翻译
   - 不需要写到具体色号，描述到位即可
3. **方式3（竞品首图）**：读取D列竞品商品链接的第一张图，生成类似风格的prompt，包含目标语言商品信息

## 执行步骤

### 0. 自动查找 Excel

在指定目录下找到最新的 `.xlsx` 文件（按修改时间排序）。

### 1. 读取 Excel

用 Python + openpyxl 读取，从第4行开始遍历每一行商品数据。跳过I列已有内容且未修改B列的行（避免重复生成）。

### 2. 生成 Listing 内容

对每个需要处理的商品行（I列为空或B列有更新的），依次生成 J~N 列内容：
- J列：目标语言商品名（B列中文名的直接翻译，不额外发挥）
- K列：三段式目标语言描述（上目标语言下中文）
- L列：目标语言tag（上目标语言下中文）
- M列：目标语言规格
- N列：目标语言卖点（上目标语言下中文，简洁有力）

### 3. 生成图片 Prompt

对 G 列有值且 O 列为空的行，根据图片生成方式生成 O 列 prompt。

### 4. 写回 Excel

用 openpyxl 将所有生成内容写回对应单元格，保存原文件。

注意：
- J、K、N 列的"上目标语言下中文"格式，在单元格内用换行符分隔
- 保留用户填写的 A~I 列内容不变

### 5. 完成

告诉用户：
- 处理了多少个商品
- 文件保存位置
- 提醒用户检查生成内容

## 执行原则

- **不覆盖用户数据**——A~I 列是用户填写的，绝不修改
- **增量处理**——只处理新行或修改过的行，已生成的不重复处理
- **翻译忠实**——商品名为B列的直接翻译，不额外添加修饰词或营销词
- **描述质量**——目标语言描述要符合当地电商用语习惯，不是逐字直译
- **Tag 合规**——严格遵守目标平台的标签规范，禁止营销词
- **模版用户定义**——图片 Prompt 模版完全由用户提供，skill 只负责填入商品信息
- **Prompt 可用**——生成的图片 Prompt 要直接能用于 Midjourney / DALL-E 等工具
