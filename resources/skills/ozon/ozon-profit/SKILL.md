# Ozon 利润账本

> 自动查询 Ozon 已签收订单，匹配国际运费和进货价，计算每笔利润并写入 Excel。Ozon 跨境电商利润核算全自动化，告别手工记账。

## 亮点

- **自动拉单** — 查询 Ozon 后台 FBO/FBS 已签收订单，自动去重，只记录新订单
- **全成本拆解** — 售价、销售佣金、末公里配送、国际运输代理、收单费，逐项核算
- **汇率自动折算** — 从卢布自动折算人民币，支持实时汇率查询
- **运费/进价自动匹配** — 从辅助表按运单号自动匹配国际运费和采购价，计算净利润
- **辅助表用户自定义** — 运费和进价的辅助表结构由你定义，适配你的物流商和采购工具
- **增量更新** — 只追加新订单，不删除已有记录，安全可靠

## 前置要求

- **Claude Code CLI**（[安装指南](https://docs.anthropic.com/en/docs/claude-code)）
- **平台 Seller API 访问权限**（如 Ozon 的 Client-Id 和 Api-Key）
- **平台 MCP Server**（用于调用平台 API 查询订单和财务数据）
  - 以 Ozon 为例，需要支持：`fbo_posting_list`、`fbs_posting_list`、`fbo_posting_get`、`fbs_posting_get`、`product_info`、`finance_transactions`
- Python + openpyxl（用于读写 Excel）
- Web Search 能力（用于查询实时汇率）

## 使用方法

将此文件放入 Claude Code 的 commands 目录：

```
~/.claude/commands/ozon-profit.md
```

或在 Claude Code 对话中直接输入 `/ozon-profit`。

**触发关键词：** "更新账本"、"查账"、"看看利润"

**首次使用前请配置：**
1. Ozon API 的 Client-Id 和 Api-Key（在 Ozon Seller MCP Server 中配置）
2. 账本 Excel 文件的存放路径
3. 辅助表结构（见下方说明，按你的物流商和采购工具自定义列名和匹配逻辑）

## 账本文件

请创建一个 Excel 文件作为利润账本，包含至少 3 个 Sheet：

- **Sheet1「账本」**：主账本，记录每笔订单的完整利润
- **Sheet2「运费明细」**：你的国际物流商提供的运费数据
- **Sheet3「采购价」**：你的采购工具/ERP导出的采购价格

**规则：** 每次更新追加新行，不删除已有记录

### 主账本表格结构（Sheet1）

| 列 | 列名 | 说明 | 数据来源 |
|---|---|---|---|
| A | 记账日期 | 本次记录的日期（格式 YYYY-MM-DD） | 自动填写 |
| B | 到账日期 | 货款到账日期（平台结算周期参考，如 Ozon T+7） | finance_transactions |
| C | 订单号 | 平台订单号 | 平台API |
| D | 追踪号码 | 物流追踪号 | 平台API |
| E | 商品名称 | 商品名称 | product_info |
| F | Ozon链接 | https://ozon.ru/context/detail/id/{product_id}/ | product_info |
| G | 售价（RMB） | 买家支付的售价，从RUB折算 | finance_transactions |
| H | 销售佣金（RMB） | Ozon销售佣金（约12%） | finance_transactions |
| I | 末公里配送（RMB） | LastMile PVZ配送费 | finance_transactions |
| J | 国际运输代理（RMB） | rFBS跨境物流代理费（固定-15RUB/单） | finance_transactions |
| K | 收单费（RMB） | 支付处理费 | finance_transactions |
| L | 平台费用（RMB） | 销售佣金+末公里配送+国际运输代理+收单费（均为负数，取绝对值） | 计算 |
| M | 最终收入（RMB） | 售价 - 平台费用（绝对值） | 计算 |
| N | 进货价（RMB） | 采购成本 | 辅助Sheet自动匹配 |
| O | 国际运费（RMB） | 国际物流费用 | 辅助Sheet自动匹配 |
| P | 利润（RMB） | 最终收入 - 进货价 - 国际运费 | 计算 |
| Q | 备注 | 补充说明（含原始RUB金额） | 自动填写 |

### 辅助Sheet结构（用户自定义）

辅助表用于存储你的物流和采购数据，**列结构由你根据自己的工具决定**。

#### Sheet2「运费明细」

存放你使用的国际物流商（如跨境巴士、燕文、云途等）的运费数据。

**最低要求：** 必须有一列包含**追踪号码**，一列包含**运费金额**。

示例结构（仅供参考，按你的物流商调整）：

| 列 | 列名 |
|---|---|
| A | 填写日期 |
| B | 追踪号码 |
| ... | （你的物流商的其他字段） |
| N | 运费费用(¥) |

**首次使用时，请告诉 Claude：**
- 哪一列是追踪号码（用于匹配）
- 哪一列是运费金额（用于回填）

#### Sheet3「采购价」

存放你的采购工具（如妙手ERP、马帮ERP、店小秘等）导出的采购价格数据。

**最低要求：** 必须有一列包含**追踪号码**，一列包含**采购金额**。

示例结构（仅供参考，按你的工具调整）：

| 列 | 列名 |
|---|---|
| A | 填写日期 |
| B | 采购金额(¥) |
| C | 追踪号码 |

**首次使用时，请告诉 Claude：**
- 哪一列是追踪号码（用于匹配）
- 哪一列是采购金额（用于回填）

## 执行步骤

### 第一步：获取已签收订单（平台后台）

用平台 MCP 查询最近已签收的订单，按时间倒序排列。查询时间范围：从账本中最后一条记录的日期开始，到今天。

### 第二步：去重

读取账本 Sheet1「账本」，提取已记录的订单号（C列），排除已记录的订单。

### 第三步：获取订单详情

对每个新订单：
1. 用 `fbo_posting_get` 或 `fbs_posting_get` 获取订单详情（追踪号码、商品信息）
2. 用 `product_info` 获取商品名称和链接。如果订单包含多个颜色/SKU，只取其中一个SKU的product_id来生成链接即可
3. 用 `finance_transactions` 获取该订单的财务明细（售价、佣金、物流费等）

### 第四步：计算利润

- **售价（RMB）**：从 finance_transactions 获取售价，按当前汇率折算成人民币
  - 汇率获取方式：WebSearch 搜索实时汇率
  - 如搜不到实时汇率，使用默认值并标注
- **平台费用（RMB）**= 销售佣金 + 末公里配送 + 国际运输代理 + 收单费（四项均为负数）
- **最终收入（RMB）**= 售价 + 平台费用（即售价减去各项费用绝对值）
- **进货价**：先留空，第六步自动匹配
- **国际运费**：先留空，第六步自动匹配
- **利润**：如进货价和国际运费都已填则 = 最终收入 - 进货价 - 国际运费，否则留空

### 第五步：写入新订单到账本

用 Python + openpyxl 将每条订单写入账本 Sheet1：
- 找到第一个空行，从该行开始写入
- 每条订单占一行，N列（进货价）和O列（国际运费）暂时留空
- L列（平台费用）= H列+I列+J列+K列
- M列（最终收入）= G列+L列
- 写入完成后更新合计行（最后一行），对G~P各数值列求和

### 第六步：匹配国际运费和进价

新订单写入后，对账本中所有 N列（进货价）和 O列（国际运费）为空的记录：
1. 提取其 D列（追踪号码）
2. 去 Sheet2「运费明细」中按追踪号码查找匹配的记录，将运费金额填入 O列
3. 去 Sheet3「采购价」中按追踪号码查找匹配的记录，将采购金额填入 N列
4. 匹配完成后，对 N列和 O列都不为空的行，计算 P列 = M列 - N列 - O列（利润）

> 匹配时使用的具体列，取决于你在首次配置时告诉 Claude 的对应关系。

### 第七步：输出报告

告诉用户：
- 本次新增了 X 笔订单记录
- 匹配到了 Y 笔国际运费，Z 笔进货价
- 匹配后利润已自动计算的有 W 笔
- 未匹配的订单：列出追踪号码，提醒用户后续补充数据到辅助Sheet

## 辅助数据更新

当用户提供新的物流运费数据或采购价数据时：
1. 先更新到对应的辅助Sheet（运费明细 或 采购价）
2. 然后触发第六步的匹配逻辑，把新数据回填到账本
3. 输出匹配结果

---

## 执行原则

- **安全第一**——只追加，不删除，不修改已有记录
- **去重严谨**——写入前必须检查订单号是否已存在
- **汇率透明**——使用的汇率要告知用户，默认值和实际值差异大时提醒
- **匹配失败要提醒**——未匹配到运费/进价的订单必须列出，不能静默跳过
- **辅助表灵活**——匹配列由用户自定义，适配不同物流商和采购工具
- **数据可追溯**——备注列保留原始RUB金额，方便用户核对
