# TikTok 内容规划

## 规划框架

### 内容金字塔

```
          【爆款内容】(5%)
              ↑
         【热点跟进】(15%)
              ↑
        【系列内容】(30%)
              ↑
        【基础内容】(50%)
```

**基础内容** - 建立账号认知
- 固定主题，稳定更新
- 展现账号核心价值

**系列内容** - 深度垂直
- 主题系列化
- 培养观看习惯

**热点跟进** - 流量获取
- 热门话题/音乐
- 时效性内容

**爆款内容** - 破圈传播
- 创意突破
- 情绪共鸣

## 内容日历规划

### 规划周期

**月度规划**:
- 确定月度主题
- 重要节点营销
- 系列内容安排

**周度规划**:
- 具体视频选题
- 发布时间安排
- 热点跟进计划

**每日执行**:
- 拍摄剪辑
- 互动维护
- 数据分析

### 发布节奏

**更新频率建议**:
- 新手期：每日1-2条
- 成长期：每日1条 + 质量
- 成熟期：保持稳定，质量优先

**黄金发布时间**:
| 用户类型 | 推荐时段 |
|----------|----------|
| 学生党 | 12:00-13:00, 18:00-22:00 |
| 职场人 | 07:00-08:00, 19:00-23:00 |
| 宝妈 | 09:00-11:00, 21:00-23:00 |

### 内容配比

**阶段一：冷启动期** (0-10K粉丝)
- 基础内容：70%
- 热点跟进：30%

**阶段二：成长期** (10K-100K粉丝)
- 基础内容：50%
- 系列内容：30%
- 热点跟进：15%
- 爆款尝试：5%

**阶段三：成熟期** (100K+粉丝)
- 基础内容：40%
- 系列内容：40%
- 爆款内容：15%
- 热点跟进：5%

## 选题策略

### 选题来源

**用户需求**:
- 评论区问题
- 私信咨询
- 粉丝群讨论

**竞品分析**:
- 同行爆款内容
- 跨平台优质内容
- 改编创新

**热点追踪**:
- 抖音热榜
- 节日营销
- 社会热点

**平台工具**:
- 创作者服务
- 热门话题
- 音乐推荐

### 选题评估矩阵

```
高兴趣度 | 优先制作   | 谨慎评估
        |           |
--------+-----------+--------
        |           |
低兴趣度 | 长尾储备   | 放弃
        低制作难度    高制作难度
```

**制作难度评估**:
- 拍摄难度
- 剪辑难度
- 成本投入
- 时间周期

## 系列内容设计

### 系列类型

**知识科普类**:
- 分点讲解

- 建立权威

**技能教学类**:

**剧情连载类**:
- 悬念设置
- 情节延续
- 追剧效应

**挑战打卡类**:
- 目标明确
- 进程可追踪
- 互动参与

### 系列规划模板

**系列名称**: [统一标识]
**内容数量**: 5-10期为一季
**更新频率**: 每周X期
**内容大纲**:
- 第1期：引入话题，建立认知
- 第2-N期：逐步深入
- 最后一期：总结回顾

## 内容模板库

### 开头模板 (前3秒)

**提问式**:
- "你有没有遇到过这种情况？"
- "为什么XX总是XX？"

**痛点式**:
- "这个XX真的太气人了！"
- "终于找到解决XX的方法了！"

**结果式**:
- "跟着我做，轻松学会XX！"
- "只需XX分钟，XX就能搞定！"

**悬念式**:
- "这个方法我藏了很久..."
- "没想到还能这样操作！"

### 结构模板

**干货类**:
1. 痛点引入 (5秒)
2. 方法展示 (20-40秒)
3. 效果验证 (5秒)
4. 总结引导 (5秒)

**种草类**:
1. 产品展示 (5秒)
2. 使用演示 (20-30秒)
3. 效果对比 (10秒)
4. 购买引导 (5秒)

**剧情类**:
1. 冲突设置 (5秒)
2. 情节展开 (30-45秒)
3. 反转高潮 (5秒)
4. 开放结尾 (5秒)
