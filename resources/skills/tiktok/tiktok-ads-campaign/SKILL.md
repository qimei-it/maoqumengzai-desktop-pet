# TikTok 广告投放

## 广告账户设置

### 注册流程

1. 访问 [TikTok Ads](https://ads.tiktok.com/)
2. 创建企业账户
3. 填写公司信息
4. 提交审核（24-48小时）

### 账户结构

```
广告账户
├── 推广系列 (Campaign) - 广告目标
│   ├── 广告组 (Ad Group) - 受众、预算、出价
│   │   ├── 广告 (Ad) - 创意素材
│   │   ├── 广告 (Ad)
│   │   └── 广告 (Ad)
│   └── 广告组 (Ad Group)
└── 推广系列 (Campaign)
```

## 广告类型

### 主要广告形式

| 广告类型 | 特点 | 适用场景 |
|----------|------|----------|
| 信息流广告 | 原生展示，用户体验好 | 品牌曝光、产品推广 |
| 品牌挑战赛 | 用户参与，病毒传播 | 品牌活动、新品发布 |
| 品牌效果 | AR滤镜、贴纸 | 品牌互动、用户参与 |
| 购物广告 | 直接转化 | 电商销售、店铺引流 |
| TopView | 开屏展示 | 大品牌曝光 |

### 广告目标

| 目标 | 说明 | 适用场景 |
|------|------|----------|
| Reach | 最大化触达 | 品牌曝光 |
| Traffic | 网站访问 | 流量获取 |
| App Installs | 应用下载 | App推广 |
| Conversions | 转化行为 | 销售、注册 |
| Catalog Sales | 目录销售 | 电商多产品 |

## 受众定向

### 定向维度

**人口统计**:
- 地理位置（国家/地区/城市）
- 年龄（13-55+）
- 性别
- 语言

**兴趣行为**:
- 兴趣类别（美妆、科技、运动等）
- 行为标签（购买行为、视频互动）
- 设备类型
- 网络环境

**自定义受众**:
- 网站访客（需安装Pixel）
- 客户列表
- App用户

### 受众规模建议

```
受众过窄：< 50万 - 曝光不足
受众适中：50万-500万 - 推荐
受众过宽：> 500万 - 可能不够精准
```

## 预算与出价

### 预算设置

| 预算类型 | 说明 | 建议 |
|----------|------|------|
| 日预算 | 每日最高花费 | 最低$20/天 |
| 总预算 | 推广期总花费 | 根据活动周期 |

### 出价策略

| 策略 | 说明 | 适用场景 |
|------|------|----------|
| 最低成本 | 自动优化获客成本 | 新手、测试期 |
| 成本上限 | 控制最高成本 | 追求ROI |
| 手动出价 | 自主设置出价 | 有经验的优化师 |

## 广告创意

### 视频规格

| 项目 | 要求 |
|------|------|
| 时长 | 5-60秒（推荐15-30秒） |
| 比例 | 9:16（竖屏）或 1:1（方形） |
| 格式 | MP4, MOV |
| 大小 | 最大500MB |

### 创意要点

**前3秒黄金法则**:
- 抓住注意力
- 展示核心卖点
- 引发情感共鸣

**创意元素**:
- 热门音乐
- 字幕文案
- 品牌Logo
- 行动号召（CTA）

## 效果优化

### 关键指标

| 指标 | 说明 | 优化方向 |
|------|------|----------|
| CTR | 点击率 | 优化创意、文案 |
| CPC | 点击成本 | 优化定向、出价 |
| CVR | 转化率 | 优化落地页 |
| CPA | 获客成本 | 综合优化 |
| ROAS | 广告回报率 | ROI核心指标 |

### A/B测试

测试变量:
- 创意素材（视频/图片）
- 文案标题
- 受众定向
- 出价策略
- 落地页
