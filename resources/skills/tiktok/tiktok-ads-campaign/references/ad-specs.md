# TikTok 广告规格参考

## 视频广告规格

### 信息流广告
| 规格 | 要求 |
|------|------|
| 视频格式 | MP4, MOV, WebM |
| 视频比例 | 9:16 (竖屏), 1:1 (方屏), 16:9 (横屏) |
| 视频时长 | 5-60秒 |
| 文件大小 | <500MB |
| 分辨率 | ≥720×1280 (竖屏) |

### 图片广告
| 规格 | 要求 |
|------|------|
| 图片格式 | JPG, PNG |
| 图片比例 | 9:16, 1:1, 16:9 |
| 文件大小 | <2MB |
| 分辨率 | ≥1080×1080 |

## 创意最佳实践

### 黄金3秒原则
- 第1秒: 视觉冲击
- 第2秒: 提出问题/需求
- 第3秒: 给出解决方案

### 高转化创意元素
- 情感共鸣
- 痛点直击
- 社会认同
- 紧迫感营造
- CTA明确

## 出价策略

### 出价方式
| 方式 | 说明 | 适用场景 |
|------|------|---------|
| oCPM | 按千次展示优化 | 品牌曝光 |
| oCPC | 按点击优化 | 流量获取 |
| CPA | 按行动优化 | 转化目标 |

### 出价建议
```
初始出价 = 建议出价 × 0.8
观察期 = 24-48小时

优化策略:
- CTR >2%: 提高出价扩量
- CTR <1%: 优化创意
- CPA >目标价: 降低出价
```
