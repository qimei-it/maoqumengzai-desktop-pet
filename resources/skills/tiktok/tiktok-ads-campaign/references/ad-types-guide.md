# TikTok 广告类型指南

## 广告类型概览

### 开屏广告

**特点**:
- 全屏展示，强曝光
- 用户打开APP时首屏呈现
- 支持静态/动态视频
- 品牌曝光效果佳

**规格要求**:
| 项目 | 要求 |
|------|------|
| 尺寸 | 1080×1920px |
| 时长 | 3-5秒 |
| 格式 | MP4/JPG/PNG |
| 大小 | <2MB |

**适用场景**:
- 新品发布
- 品牌宣传
- 大促活动
- 市场教育

**投放建议**:
- 预算充足（万级以上）
- 品牌知名度提升
- 配合其他广告形式

### 信息流广告

**特点**:
- 原生融入用户内容流
- 不干扰用户体验
- 支持多种转化目标
- 性价比高

**广告样式**:
- **横向视频**: 16:9，适合品牌展示
- **竖屏视频**: 9:16，沉浸体验
- **图片广告**: 静态展示
- **轮播广告**: 多图展示

**转化目标**:
| 目标 | 说明 | 适用场景 |
|------|------|----------|
| 应用下载 | 引导下载APP | APP推广 |
| 落地页访问 | 跳转H5页面 | 活动页/商品页 |
| 商品销量 | 直接购买商品 | 电商带货 |
| 潜在客户 | 收集销售线索 | B2B/服务业 |
| 视频播放量 | 品牌视频曝光 | 品牌宣传 |

**适用场景**:
- 商品推广
- APP下载
- 活动推广
- 品牌曝光

### 搜索广告

**特点**:
- 用户主动搜索触发
- 意图明确，转化率高
- 按点击付费CPC
- 精准流量获取

**展现位置**:
- 搜索结果顶部
- 搜索结果中部
- 品牌专区

**关键词策略**:
- **品牌词**: 自有品牌/产品名
- **品类词**: 行业通用词
- **竞品词**: 竞争对手品牌词
- **长尾词**: 具体需求描述

**适用场景**:
- 精准流量获取
- 竞品拦截
- 品词保护
- 高意向用户转化

### DMP定向广告

**特点**:
- 精准人群定向
- 多维度标签筛选
- 高ROI潜力
- 灵活出价

**定向维度**:
- **基础属性**: 年龄、性别、地域、学历
- **兴趣偏好**: 兴趣标签、关注话题
- **行为特征**: APP使用、浏览行为
- **消费特征**: 消费水平、购买偏好

**定向策略**:
| 策略 | 说明 | 适用场景 |
|------|------|----------|
| 广泛定向 | 大流量测试 | 新品测试 |
| 精准定向 | 高转化目标 | ROI优化 |
| 排除定向 | 避免浪费 | 活动定向 |
| 相似人群 | Lookalike扩展 | 精准人群扩展 |

## 广告创意制作

### 视频广告创意

**黄金3秒原则**:
- 第1秒：强视觉冲击
- 第2秒：产品展示/痛点
- 第3秒：行动引导

**创意结构**:
```
开头(3秒) → 产品展示(10-20秒) → 效果证明(5秒) → CTA(5秒)
```

**内容类型**:
1. **产品演示型**: 展示产品功能效果
2. **场景代入型**: 使用场景真实呈现
3. **对比反差型**: 使用前后对比
4. **剧情故事型**: 故事情感化表达
5. **明星代言型**: 名人背书增加信任

### 图片广告创意

**设计要点**:
- 产品突出，清晰可见
- 文案简洁有力
- 色彩对比强烈
- CTA按钮明显

**构图技巧**:
- 三分法则
- 中心聚焦
- 黄金分割
- 视觉引导

### 文案创作技巧

**标题公式**:
- 痛点+解决方案："XX不好用？试试这个"
- 数字化表达："3天见效，无效退款"
- 制造悬念："这个秘密我藏了很久"
- 利益引导："限时优惠，立省XX元"

**CTA优化**:
- 明确行动："立即购买"/"了解更多"
- 制造紧迫感："限时特惠"/"仅剩XX件"
- 降低门槛："免费试用"/"先试后买"
- 社会认同："已有XX人购买"

## 广告投放策略

### 出价策略

**出价方式**:
| 方式 | 说明 | 适用场景 |
|------|------|----------|
| CPC | 按点击付费 | 流量获取 |
| CPM | 按千次展示付费 | 品牌曝光 |
| oCPM | 智能优化出价 | 转化优化 |
| CPA | 按行动付费 | 效果广告 |

**出价技巧**:
- 新广告：中等偏上出价
- 稳定期：根据ROI调整
- 旺季：提高出价抢量
- 淡季：降低出价控本

### 预算分配

**预算规划模型**:
```
测试期(20%) → 优化期(30%) → 放量期(50%)
```

**分阶段预算**:
1. **测试阶段**: 小预算多测试
2. **优化阶段**: 集中预算优素材
3. **放量阶段**: 大预算投放优质广告

### A/B测试

**测试维度**:
- 素材类型：视频/图片
- 创意角度：不同卖点
- 定向人群：不同人群包
- 落地页：不同页面设计
- 出价方式：不同出价策略

**测试方法**:
- 单变量测试
- 足够样本量
- 数据周期观察
- 胜出方案放量

## 广告优化技巧

### 数据监控指标

**曝光相关**:
- 展现量：广告曝光次数
- CTR：点击率（>1%为健康）
- CPC：单次点击成本

**转化相关**:
- 转化量：完成目标动作数
- CVR：转化率
- CPA：单次转化成本

**效果相关**:
- ROI：投入产出比
- ROAS：广告回报率
- LTV：客户终身价值

### 优化方向

**曝光不足**:
- 提高出价
- 放宽定向
- 优化素材相关性
- 增加预算

**点击率低**:
- 优化创意素材
- 优化标题文案
- 精准人群定向
- 测试不同素材

**转化率低**:
- 优化落地页体验
- 精准流量定向
- 优化产品卖点
- 降低转化门槛

**ROI低**:
- 降低出价/预算
- 暂停低效广告
- 优化定向精准度
- 提升转化率

### 否词使用

**否词类型**:
- **品牌词**: 避免品牌词浪费
- **无关词**: 排除无关流量
- **意向低词**: 排除低意向词

**否词策略**:
- 搜索词报告分析
- 逐步添加否词
- 定期清理否词
- 避免过度否定
