# TikTok Competitor Monitor

## 核心能力

### 1. 竞品账号追踪

**监控维度**
- 粉丝增长趋势
- 内容发布频率
- 互动率变化
- 爆款视频识别
- 合作品牌分析

**追踪指标**
```python
竞品档案 = {
    "账号信息": {...},
    "粉丝数据": "增长曲线",
    "内容策略": "发布时间/频率/类型",
    "互动表现": "点赞/评论/分享率",
    "商业价值": "商单价/带货能力"
}
```

### 2. 价格监控

**监控类型**
- 同类产品价格追踪
- 促销活动监控
- 价格变动预警
- 差异化定价分析

**价格分析输出**
```
产品              | 竞品A  | 竞品B  | 我方   | 建议
-----------------|--------|--------|--------|--------
润唇膏           | ¥79   | ¥99   | ¥89   | 适中
保湿面膜(10片)   | ¥59   | ¥49   | ¥69   | 偏高
抗老精华         | ¥299  | ¥199  | ¥259  | 适中
```

### 3. 爆款捕捉

**识别标准**
- 播放量 > 10万
- 点赞率 > 5%
- 评论量 > 1000
- 分享量 > 500

**爆款分析**
- 内容主题分析
- BGM/音乐趋势
- 发布时间规律
- 脚本结构拆解
- 视觉风格总结

### 4. 内容策略分析

**分析维度**
- 内容类型分布
- 脚本风格分析
- 视频节奏研究
- 话题标签分析
- 合作品牌画像

**策略输出**
```
竞品内容策略:
├─ 主要内容类型: 测评(40%) / 教程(30%) / 剧情(20%)
├─ 发布规律: 每天19:00-21:00高峰
├─ 视频时长: 30-60秒为主
├─ BGM偏好: 热门抖音神曲
└─ 合作品牌: 美妆为主(80%)
```

### 5. 市场机会发现

**机会识别**
- 内容空白点
- 价格空白区
- 品类机会
- 达人合作机会

## 监控指标

### 账号健康度
| 指标 | 计算方式 | 健康值 |
|------|---------|--------|
| 粉丝增长率 | (本周-上周)/上周 | >5% |
| 互动率 | (点赞+评论)/粉丝量 | >8% |
| 爆款率 | 爆款视频/总视频 | >10% |
| 更新频率 | 视频数/天数 | >0.5 |

### 内容表现
| 指标 | 计算 | 优秀值 |
|------|------|--------|
| 平均播放量 | 总播放/视频数 | >5万 |
| 点赞率 | 点赞/播放 | >5% |
| 评论率 | 评论/播放 | >1% |
| 分享率 | 分享/播放 | >0.5% |

## 使用示例

### 示例 1: 价格监控
```python
from price_monitor import PriceMonitor

monitor = PriceMonitor()
price_report = monitor.analyze_prices(
    product="润唇膏",
    competitors=["店铺A", "店铺B"],
    price_range=(50, 150)
)
```

### 示例 2: 爆款分析
```python
from viral_detector import ViralDetector

detector = ViralDetector()
viral_analysis = detector.analyze_viral_videos(
    account="@competitor",
    min_views=100000,
    days=30
)
```

## 最佳实践

### ✅ 监控原则
1. **合法合规**: 尊重隐私，不窃取数据
2. **定期更新**: 每周更新竞品数据
3. **关键指标**: 关注核心指标，不盲目追求数据量
4. **行动导向**: 监控是为了优化自身策略

### ❌ 避免行为
1. 盲目复制竞品内容
2. 恶意价格战
3. 过度关注竞品忽视自身
4. 使用非法手段获取数据
