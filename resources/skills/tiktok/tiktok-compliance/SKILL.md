# TikTok 平台合规

## 内容规范

### 禁止内容

**绝对禁止**:
- 暴力血腥内容
- 色情低俗内容
- 违法犯罪内容
- 政治敏感内容
- 宗教极端内容
- 种族歧视内容

**侵权内容**:
- 盗用他人视频
- 未授权音乐
- 品牌商标侵权
- 未经授权肖像

### 敏感内容

| 类型 | 风险等级 | 建议 |
|------|----------|------|
| 医疗健康 | 高 | 谨慎宣传效果 |
| 金融理财 | 高 | 避免承诺收益 |
| 减肥瘦身 | 中 | 避免夸大效果 |
| 母婴育儿 | 中 | 遵循专业建议 |
| 宠物内容 | 低 | 正常展示 |

### 内容规范要点

- 原创内容优先
- 引用需注明来源
- 避免虚假宣传
- 尊重他人权益

## 商品合规

### 禁售品类

**绝对禁售**:
- 毒品及吸毒工具
- 武器弹药
- 濒危动植物
- 盗版商品
- 假冒伪劣产品
- 医疗器械（部分）
- 处方药

**限制销售**（需资质）:
- 化妆品（需备案）
- 食品（需许可）
- 保健品（需认证）
- 母婴产品（需检测）
- 电子烟（部分地区禁止）

### 商品描述规范

**必须包含**:
- 产品名称
- 规格参数
- 材质成分
- 使用说明
- 注意事项

**禁止行为**:
- 虚假宣传
- 夸大功效
- 误导消费者
- 价格欺诈

### 不同市场合规要求

| 市场 | 特殊要求 |
|------|----------|
| 美区 | FDA认证、FCC认证 |
| 英区 | CE认证、UKCA认证 |
| 欧盟 | CE认证、GDPR合规 |
| 东南亚 | 各国标准不同 |

## 广告合规

### 广告内容规范

**禁止内容**:
- 虚假宣传
- 误导性比较
- 未经授权使用他人形象
- 侵权内容

**必须披露**:
- 广告标识
- 赞助关系
- 优惠条件

### 广告审核

**审核要点**:
- 内容真实性
- 目标落地页合规
- 文案准确性
- 图片/视频合规

**常见拒绝原因**:
- 落地页无法访问
- 内容与落地页不符
- 涉及禁售品类
- 文案违规

## 税务合规

### 税务类型

| 税种 | 说明 | 市场区 |
|------|------|--------|
| VAT | 增值税 | 英区、欧盟 |
| GST | 商品服务税 | 东南亚 |
| Sales Tax | 销售税 | 美区 |

### VAT注册

**英国VAT**:
- 年销售额>£85,000需注册
- 可自愿注册
- 需要英国地址

**欧盟VAT**:
- 各国门槛不同
- 需要当地VAT号
- IOSS清关

### 税务申报

- 定期申报（通常按季度）
- 保留交易记录
- 了解当地税率
- 必要时咨询专业税务顾问

## 知识产权

### 商标保护

- 注册自有商标
- 避免侵权他人商标
- 发现侵权及时投诉

### 版权保护

- 原创内容申请版权
- 使用授权素材
- 避免盗用他人内容

### 专利保护

- 了解产品专利情况
- 避免销售侵权产品

## 违规处理

### 违规类型与处罚

| 违规类型 | 处罚措施 |
|----------|----------|
| 轻微违规 | 警告、内容下架 |
| 中度违规 | 限流、功能限制 |
| 严重违规 | 封号、永久禁用 |

### 申诉流程

```
收到违规通知
    ↓
分析违规原因
    ↓
准备申诉材料
    ↓
提交申诉
    ↓
等待审核结果
```

### 账号保护

- 定期检查账号状态
- 及时处理违规通知
- 保留合规证据
- 了解平台最新规则
