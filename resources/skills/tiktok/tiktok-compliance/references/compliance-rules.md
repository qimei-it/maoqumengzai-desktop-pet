# TikTok 合规规范参考

## 内容合规红线

### 禁止内容类型
| 类型 | 说明 | 后果 |
|------|------|------|
| 虚假宣传 | 夸大效果、不实承诺 | 内容限流/封号 |
| 侵权内容 | 抄袭、盗用 | 视频下架/扣分 |
| 违禁品 | 违规商品展示 | 店铺封禁 |
| 低俗内容 | 色情、暴力 | 账号封禁 |
| 引导站外 | 微信、二维码等 | 限流警告 |

### 广告合规
```
【必须标明】
├─ #广告 标签
├─ 广告主信息
└─ 真实用户评价

【禁止行为】
├─ 虚假宣传
├─ 对比贬低
└─ 极端用语
```

## 平台规则更新

### 2024年重点规则
1. **真实宣传**: 不得夸大产品效果
2. **用户保护**: 禁止欺诈行为
3. **知识产权**: 尊重版权，禁止搬运
4. **未成年人保护**: 特殊时段内容管控

### 处罚机制
| 违规类型 | 首次 | 再犯 |
|---------|------|------|
| 轻微违规 | 警告 | 内容限流 |
| 中度违规 | 内容下架 | 功能限制 |
| 严重违规 | 账号封禁 | 永久封禁 |

## 合规检查清单

- [ ] 无敏感词汇

### 直播前检查
- [ ] 主播形象合规
- [ ] 产品资质齐全
- [ ] 话术无违规
