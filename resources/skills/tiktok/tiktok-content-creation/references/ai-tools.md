# TikTok AI 创作工具指南

## AI 文案生成

### ChatGPT

**应用场景**:
- 视频脚本创作
- 标题文案生成
- 评论区回复
- 话题标签建议

**使用技巧**:
**脚本生成**:
```
提示词模板：
"为 TikTok 创作一个关于[主题]的短视频脚本，
目标受众是[人群]，风格要求[风格/调性]，
时长约[秒数]，包含开头吸引、中间内容、结尾CTA"
```

**标题生成**:
```
提示词模板：
"为关于[主题]的TikTok视频生成10个吸引人的标题，
要求：1)简洁有力 2)有情绪点 3)制造悬念 4)包含数字"
```

**爆款文案**:
```
提示词模板：
"分析TikTok[领域]的爆款内容规律，
生成符合该平台调性的文案模板，
包含：开头钩子、价值输出、情绪共鸣、行动号召"
```

## AI 工具组合工作流

### 高效创作流程

```
1. 选题策划
   └→ ChatGPT：创意brainstorming

2. 脚本创作
   └→ Claude：详细脚本撰写

3. 素材准备
   ├→ Midjourney：封面图生成
   └→ Stable Diffusion：场景图生成

4. 视频制作
   ├→ Runway：背景视频
   ├→ HeyGen：虚拟人出镜
   └→ 剪映：剪辑合成

5. 音频制作
   ├→ Suno AI：背景音乐
   └→ ElevenLabs：配音

6. 发布优化
   ├→ AI：标题标签优化
   └→ AI：发布时间建议
```
