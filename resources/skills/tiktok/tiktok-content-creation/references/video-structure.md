# TikTok 视频结构参考

## 爆款视频结构模板

### 问题解决型
```
开头 (1-3秒): 痛点/问题呈现
├─ "还在为xxx烦恼？"
├─ "这个方法太绝了！"
└─ 视觉冲击

发展 (4-15秒): 解决方案展示
├─ 问题分析
├─ 方法介绍
└─ 实际演示

高潮 (16-45秒): 效果展示
├─ 对比呈现
├─ 结果证明
└─ 情感共鸣

结尾 (46-60秒): 引导互动
├─ "关注我了解更多"
├─ "评论区留言xxx"
└─ 挑战互动
```

### 情感共鸣型
```
开头: 情绪钩子
├─ 温馨/感动场景
└─ BGM烘托

发展: 故事叙述
├─ 人物/事件介绍
└─ 情感递进

高潮: 情感爆发
├─ 转折点
└─ 情绪顶点

结尾: 价值升华
├─ 主题总结
└─ 互动引导
```

## 节奏控制技巧

### 黄金分割点
- 0-3秒: 必须抓住眼球
- 3-10秒: 核心内容展开
- 10-40秒: 详细演示/叙述
- 40-60秒: 总结+引导

### 节奏变化
```
快节奏: 剪辑切换快 (<2秒/镜头)
慢节奏: 细节展示、情感渲染
混合使用: 快慢交替，保持注意力
```
