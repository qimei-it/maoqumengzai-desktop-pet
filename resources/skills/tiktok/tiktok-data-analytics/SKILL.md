# TikTok 数据分析

## 关键指标体系

### 流量指标

| 指标 | 说明 | 健康值 |
|------|------|--------|
| 播放量 | 视频曝光次数 | 持续增长 |
| 完播率 | 完整观看比例 | >15% |
| 点击率 | 点击小黄车比例 | >1% |
| 分享率 | 分享视频比例 | >0.5% |

### 转化指标

| 指标 | 说明 | 健康值 |
|------|------|--------|
| 商品点击率 | 点击商品比例 | >3% |
| 加购率 | 加入购物车比例 | >2% |
| 转化率 | 下单购买比例 | >1% |
| 客单价 | 平均订单金额 | 因品类而异 |

### 销售指标

| 指标 | 说明 | 计算公式 |
|------|------|----------|
| GMV | 商品交易总额 | 订单数 × 客单价 |
| ROI | 投资回报率 | 收入 ÷ 成本 |
| ROAS | 广告回报率 | 广告收入 ÷ 广告花费 |
| 毛利率 | 利润比例 | (收入-成本) ÷ 收入 |

## TikTok后台数据

### Seller Center数据面板

**店铺数据**:
- 总销售额 (GMV)
- 订单数量
- 平均客单价
- 退货率

**商品数据**:
- 商品浏览量
- 商品点击率
- 转化率
- 库存状态

**流量来源**:
- 自然流量占比
- 付费流量占比
- 达人带货流量
- 直播流量

### 数据分析维度

**时间维度**:
- 实时数据
- 日/周/月报表
- 同比/环比分析

**商品维度**:
- 热销商品排行
- 商品分类分析
- 新品表现跟踪

**用户维度**:
- 新老客户比例
- 用户地域分布
- 用户行为路径

## 数据驱动决策

### 分析框架

```
1. 定义问题 → 明确分析目标
2. 收集数据 → 多维度数据源
3. 分析数据 → 找出规律和异常
4. 得出结论 → 形成洞察
5. 制定策略 → 优化行动
6. 验证效果 → 持续迭代
```

### 常见问题诊断

| 问题 | 可能原因 | 分析方向 |
|------|----------|----------|
| 播放量低 | 内容质量差、标签不精准 | 优化视频、调整标签 |
| 点击率低 | 封面吸引力不够 | 优化封面、标题 |
| 转化率低 | 产品页不吸引、价格不合理 | 优化详情页、调整定价 |
| 退货率高 | 产品质量、描述不符 | 改善产品质量、准确描述 |
