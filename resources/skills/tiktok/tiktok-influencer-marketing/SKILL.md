# TikTok 网红营销

## 达人层级划分

### 达人分类

| 层级 | 粉丝数 | 特点 | 合作成本 |
|------|--------|------|----------|
| 纳米达人 | 1K-10K | 高互动率、真实感强 | $50-200 |
| 微型达人 | 10K-50K | 细分领域专业、性价比高 | $200-500 |
| 中型达人 | 50K-500K | 影响力适中、转化稳定 | $500-2000 |
| 头部达人 | 500K+ | 大流量、品牌曝光 | $2000+ |

### 选择原则

**不是粉丝越多越好**:
- 互动率比粉丝数更重要
- 受众匹配度决定转化效果
- 内容风格要符合品牌调性

## 达人筛选

### 筛选标准

**3R原则**:
- **Reach**: 触达能力（粉丝量、播放量）
- **Relevance**: 相关性（内容定位、受众画像）
- **Resonance**: 共鸣度（互动率、粉丝信任度）

### 筛选步骤

1. **明确目标**: 品牌曝光 or 销售转化
2. **确定预算**: 可承受的合作成本
3. **筛选达人**: 工具 + 人工筛选
4. **评估数据**: 播放量、互动率、转化数据
5. **沟通合作**: 谈判、签约

## 合作模式

### 合作类型

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| Affiliate | 按销售分成（10-30%） | 新品牌、测试期 |
| 坑位费 | 固定费用发布内容 | 预算明确 |
| 产品置换 | 免费产品换取内容 | 小品牌、新品 |
| 长期代言 | 持续合作 | 品牌建设 |
| 混合模式 | 基础费+分成 | 平衡风险和收益 |

## 合作流程

### 标准流程

```
1. 筛选达人
   ↓
2. 联系沟通
   ↓
3. 确认合作方式
   ↓
4. 发送产品/资料
   ↓
5. 审核内容脚本
   ↓
6. 发布内容
   ↓
7. 效果追踪
   ↓
8. 结算付款
```

### 沟通要点

**首次联系**:
- 自我介绍 + 品牌介绍
- 说明合作意向
- 提供产品信息
- 询问合作方式

**谈判技巧**:
- 了解达人以往报价
- 提供长期合作诱因
- 明确内容要求和发布时间

## 内容类型

### 合作内容形式

| 类型 | 特点 | 转化效果 |
|------|------|----------|
| 开箱展示 | 真实自然 | ⭐⭐⭐⭐ |
| 产品测评 | 专业可信 | ⭐⭐⭐⭐⭐ |
| 情景剧情 | 情感共鸣 | ⭐⭐⭐⭐ |
| 使用教程 | 实用性强 | ⭐⭐⭐⭐ |
| 生活Vlog | 自然植入 | ⭐⭐⭐ |

### 内容要求

- 符合达人个人风格
- 产品信息准确
- 包含购买链接/优惠码
- 符合平台规范

## 效果评估

### 关键指标

| 指标 | 说明 |
|------|------|
| 播放量 | 内容曝光 |
| 互动量 | 点赞+评论+分享 |
| 点击率 | 点击链接比例 |
| 转化率 | 购买转化 |
| ROI | 投入产出比 |

### ROI计算

```
ROI = (达人带来的销售额 - 达人合作成本) / 达人合作成本 × 100%

目标ROI: >200%
```
