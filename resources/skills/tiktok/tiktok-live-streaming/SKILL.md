# TikTok 直播带货

## 直播前准备

### 开通直播权限

**要求**:
- 年满16周岁
- 粉丝数≥1000（不同市场要求略有不同）
- 账号状态正常，无违规记录

### 直播间搭建

**基础设备**:
| 设备 | 推荐配置 | 预算 |
|------|----------|------|
| 手机 | iPhone 12+ 或高端安卓 | 自有 |
| 补光灯 | 环形灯/柔光灯 | $20-50 |
| 支架 | 稳定支架 | $10-30 |
| 收音 | 领夹麦克风 | $15-50 |

### 主播人设打造

**人设要素**:
1. **专业性**: 了解产品，能解答问题
2. **亲和力**: 语气友好，互动自然
3. **记忆点**: 独特风格或口头禅
4. **信任感**: 真诚推荐，不夸大

## 直播脚本模板

### 标准脚本结构

```
【开场】(5分钟)
- 问候观众
- 自我介绍
- 直播主题/福利预告
- 引导关注

【产品介绍】(每款5-10分钟)
- 产品亮点展示
- 使用场景描述
- 对比竞品优势
- 价格优惠说明
- 限时/限量话术

【互动环节】(穿插进行)
- 回答观众问题
- 抽奖/福利
- 引导分享直播间

【收尾】(5分钟)
- 总结热销产品
- 预告下场直播
- 感谢观众
```

### 产品介绍话术模板

```
【开场】"家人们，今天这款XX真的太绝了！"
【痛点】"你们是不是经常遇到XX问题？"
【解决方案】"这款产品就能完美解决..."
【展示】"来，我给你们展示一下..."(实际演示)
【优惠】"今天直播间专享价，只要XX！"
【紧迫感】"只剩XX件了，手慢无！"
【行动号召】"点击下方小黄车，立即抢购！"
```

## 直播运营技巧

### 流量获取

**预热引流**:
- 发布预热短视频
- 账号主页预告
- 社交媒体联动
- 粉丝群通知

### 转化技巧

**价格策略**:
| 产品类型 | 定价策略 | 作用 |
|----------|----------|------|
| 引流款 | 低于市场价 | 吸引人气 |
| 利润款 | 正常定价 | 主要盈利 |
| 形象款 | 高定价 | 提升档次 |

**促销手段**:
- 限时秒杀
- 满减优惠
- 买赠活动
- 组合套餐

## 直播数据分析

### 关键指标

| 指标 | 说明 | 优化方向 |
|------|------|----------|
| 观看人数 | 进入直播间人数 | 预热、引流 |
| 平均停留时长 | 观众观看时间 | 内容质量、互动 |
| 互动率 | 评论/点赞/分享 | 话术、福利 |
| 转粉率 | 新增粉丝比例 | 人设、内容 |
| 转化率 | 购买人数占比 | 产品、话术、价格 |
| GMV | 销售总额 | 综合优化 |

## 直播禁忌

- ❌ 虚假宣传，夸大效果
- ❌ 贬低竞品，恶意对比
- ❌ 引导线下交易
- ❌ 展示违禁品
- ❌ 涉及政治、宗教敏感话题
