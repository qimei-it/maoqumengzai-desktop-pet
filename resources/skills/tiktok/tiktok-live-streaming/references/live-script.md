# TikTok 直播脚本参考

## 直播流程脚本

### 开场 (0-10分钟)
```
【暖场】
主播: "欢迎新进来的宝宝们！点点关注不迷路~"
├─ 重复3-5次
├─ 介绍今日主题
└─ 引导关注、点赞

【预告】
主播: "今天给大家带来超值福利！"
├─ 介绍产品清单
├─ 预告优惠活动
└─ 设置期待感
```

### 产品讲解 (10-120分钟)
```
【产品引入】
├─ 痛点场景描述
├─ 产品解决方案
└─ 价格悬念

【详细展示】
├─ 产品特写
├─ 使用演示
├─ 对比说明
└─ 用户见证

【互动答疑】
├─ 读评论问题
├─ 解答疑问
└─ 引导下单
```

### 逼单环节 (穿插全程)
```
【限时优惠】
├─ "只有今天有这个价！"
├─ "库存只剩xxx件！"
└─ 倒计时营造

【福利发放】
├─ 戳号抽奖
├─ 口令红包
└─ 粉丝福利
```

### 收尾 (最后10分钟)
```
【最后冲刺】
├─ 爆款款最后机会
├─ 福利汇总
└─ 感谢致辞

【预告下次】
├─ 明天直播时间
├─ 预告产品
└─ 引导关注
```

## 常见话术模板

### 留人话术
- "宝宝们先别走，马上发福利！"
- "点点关注，马上抽大奖！"
- "新来的宝宝扣1，我看看有多少人"

### 逼单话术
- "只有50单，抢完就没了！"
- "这个价格只有今天！"
- "3、2、1，上链接！"

### 感谢话术
- "感谢xxx宝宝的支持！"
- "点点关注，下次直播第一时间通知你！"

## 直播间氛围营造

### 互动技巧
- 念粉丝名字
- 回复具体问题
- 连麦互动
- 抢口令游戏

### 节奏控制
- 高潮: 逼单、抽奖
- 缓和: 产品讲解、聊天
- 交替进行，保持节奏
