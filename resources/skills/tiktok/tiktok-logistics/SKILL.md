# TikTok 跨境物流

## 物流模式

### TikTok Shop物流类型

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| 官方物流 | 平台指定物流商 | 新手、小卖家 |
| 第三方物流 | 自选物流服务商 | 有物流资源 |
| 海外仓 | 目标市场本地发货 | 高销量卖家 |
| FBT | TikTok履约服务 | 美区卖家 |

### 不同市场物流方案

| 市场 | 推荐物流 | 时效 |
|------|----------|------|
| 美区 | 云途、燕文、FBT | 7-15天 |
| 英区 | 云途、燕文 | 7-12天 |
| 东南亚 | J&T、Ninja Van | 3-7天 |

## 发货流程

### 订单处理流程

```
买家下单
    ↓
订单确认（30分钟内）
    ↓
打包商品
    ↓
打印面单
    ↓
交付物流（48小时内）
    ↓
物流揽收
    ↓
物流运输
    ↓
买家签收
```

### 时效要求

| 阶段 | 时限 | 违规后果 |
|------|------|----------|
| 订单确认 | 30分钟 | 自动取消 |
| 发货 | 48小时 | 订单自动取消 |
| 送达 | 5-15天（因市场） | 影响店铺评分 |

## 运费计算

### 运费构成

```
总运费 = 首重费用 + 续重费用

首重: 通常10g起算
续重: 按每10g递增
```

### 成本控制

**降低物流成本方法**:
1. 选择轻便商品（重量<500g最佳）
2. 优化包装（减少体积重）
3. 合并发货
4. 选择性价比高的物流商
5. 物流成本控制在售价15%以内

### 运费模板

| 重量段 | 美区运费 | 英区运费 | 东南亚运费 |
|--------|----------|----------|------------|
| 0-100g | $3-5 | $2-4 | $1-2 |
| 100-500g | $5-10 | $4-8 | $2-4 |
| 500g-1kg | $10-15 | $8-12 | $4-6 |
| 1-2kg | $15-25 | $12-18 | $6-10 |

## 海外仓

### 海外仓优势

| 优势 | 说明 |
|------|------|
| 时效快 | 本地发货，1-3天送达 |
| 成本低 | 批量运输，降低单件成本 |
| 体验好 | 快速送达，提升满意度 |
| 流量加权 | 平台流量倾斜 |

### 海外仓选择

**考虑因素**:
- 仓储费用
- 头程运费
- 尾程配送
- 系统对接
- 库存管理能力

## 退换货

### 退货流程

```
买家申请退货
    ↓
卖家审核（48小时）
    ↓
同意/拒绝
    ↓
买家寄回商品
    ↓
卖家收货验收
    ↓
退款/换货
```

### 退货率控制

**降低退货率**:
1. 准确的产品描述和图片
2. 合理的尺码指南
3. 清晰的使用说明
4. 质量把控
5. 售前沟通

### 退货成本

- 退货率<5%: 正常
- 退货率5-10%: 需关注
- 退货率>10%: 需优化

## 常见问题

### Q: 发货超时怎么办？
及时与买家沟通，申请延长发货时间；如无法按时发货，主动取消订单。

### Q: 包裹丢失怎么处理？
联系物流商查询，及时补发或退款给买家。

### Q: 如何选择物流商？
综合考虑：时效、价格、服务质量、平台认可度。
