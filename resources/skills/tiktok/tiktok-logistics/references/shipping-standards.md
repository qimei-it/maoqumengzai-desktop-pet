# TikTok 物流发货规范

## 物流时效标准

### 发货时效
| 订单类型 | 时效要求 |
|---------|---------|
| 现货订单 | 48小时内发货 |
| 预售订单 | 按约定时间 |
| 定制订单 | 按约定时间 |
| 跨境订单 | 7天内发货 |

### 物流公司选择
```
【推荐物流】
├─ 顺丰速运: 服务好，速度快
├─ 中通快递: 性价比高
├─ 圆通速递: 覆盖广
└─ 韵达快递: 价格优惠

【慎用物流】
├─ 某些偏远地区快递
└─ 投诉较多的物流
```

## 包装规范

### 基础包装
- 产品保护: 防止运输损坏
- 防水防潮: 使用防水袋
- 外包装整洁: 品牌形象

### 体验优化
```
【开箱体验】
├─ 感谢卡片
├─ 使用说明
├─ 保养指南
└─ 小礼品/样品

【品牌展示】
├─ Logo/品牌色
├─ 联系方式
└─ 社媒账号
```

## 物流异常处理

### 常见问题处理
| 问题 | 处理方式 |
|------|---------|
| 延迟发货 | 主动告知+补偿 |
| 物流破损 | 补发+道歉 |
| 地址错误 | 协助修改 |
| 拒收退回 | 了解原因+处理 |

### 客户沟通话术
```
【延迟发货】
"亲亲，因xxx原因延迟发货，深表歉意！
我们已为您准备了一份小礼物补偿，预计x日送达~"

【物流异常】
"实在抱歉！我们已联系快递方核实，
马上为您处理，稍后有专人联系您！"
```
