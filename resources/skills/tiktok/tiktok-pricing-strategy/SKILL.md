## 概述

TikTok 定价策略优化助手，帮助达人和商家制定科学的价格策略，最大化收益和利润率。

---

## 核心功能

### 1. 动态定价建议

**达人侧 - 商单报价计算器**
- 基于粉丝量、互动率计算合理报价
- CPM（千次曝光）定价参考
- CPE（单次互动）成本分析
- 行业报价基准对比

**商家侧 - 商品定价优化**
- 成本加成定价法
- 竞争导向定价法
- 价值导向定价法
- 心理定价策略（如 ¥99 vs ¥100）

### 2. 竞品价格分析

- 实时竞品价格追踪
- 价格区间分布分析
- 价格战预警系统
- 差异化定价建议

### 3. 促销方案生成

- 限时折扣策略
- 满减优惠计算
- 买赠活动设计
- 组合销售定价
- 会员专享价方案

### 4. 利润率模拟

- 单品利润计算
- 不同定价场景的利润预测
- 促销活动盈亏平衡点分析
- 渠道费用（佣金、物流）计算

## 使用场景

### 场景 A: 达人接单报价
```
用户: 我有50万粉丝，互动率8%，品牌想让我发一个视频，该报多少钱？

助手分析:
├─ 粉丝量级: 中腰部达人 (10-100万)
├─ 互动率: 8% (行业优秀水平)
├─ 参考报价区间: ¥15,000 - ¥30,000
├─ CPM计算: 50万粉丝 × 8% = 4万互动
│   ¥20,000 / 40 = ¥500/千次互动
└─ 报价建议: ¥22,000 (可协商 ¥20,000-¥25,000)
```

### 场景 B: 商家商品定价
```
用户: 这个成本80元的口红，应该定什么价格？

助手分析:
├─ 成本加成法: ¥80 × 2.5 = ¥200 (传统倍率)
├─ 竞品分析:
│   ├─ 同类产品均价: ¥158-298
│   ├─ 热销价格段: ¥168-198
│   └─ 心理价位: ¥199 (比200更有吸引力)
├─ 平台费用:
│   ├─ 达人佣金: 20%
│   ├─ 平台扣点: 5%
│   └─ 物流成本: ¥5
└─ 建议定价: ¥179 (首单尝鲜价) / ¥199 (常规价)
```

### 场景 C: 促销活动设计
```
用户: 双11要搞促销，想清库存又不想亏太多

助手分析:
├─ 当前库存: 3000件
├─ 清货目标: 销售2000件以上
├─ 促销方案:
│   ├─ 方案1: 8折 + 满300减30 (需验证利润)
│   ├─ 方案2: 买2送1 (相当于67折)
│   └─ 方案3: 限时秒杀 ¥99 (引流款)
└─ 推荐: 方案2组合方案
    ├─ 主推款 8折
    ├─ 搭配款 买2送1
    └─ 引流款 限量100件 ¥99
```

|------|------|---------|

## 计算公式

### 达人报价计算
```
基础报价 = 粉丝量 × 互动率 × CPM基准
CPM基准 = ¥200 - ¥500 (根据行业和粉丝质量调整)

最终报价 = 基础报价 × 内容难度系数 × 紧急程度系数
```

### 商家利润计算
```
售价 = 成本 × (1 + 目标利润率) + 平台费用 + 物流费用

实际利润 = 售价 - 成本 - 平台佣金 - 达人佣金 - 物流费
利润率 = 实际利润 / 售价 × 100%
```

### 促销盈亏平衡
```
盈亏平衡销量 = 固定成本 / (原价 × 折扣率 - 单位可变成本)

促销利润 = (销量 × 折扣价) - (销量 × 单位成本) - 促销费用
```

## 最佳实践

### ✅ 定价原则
1. **价值导向**: 价格反映产品价值，而非成本
2. **竞争-aware**: 关注竞品但不盲从
3. **灵活调整**: 根据数据和反馈动态调整
4. **透明沟通**: 价格变动有合理解释

### ❌ 常见误区
1. 只打价格战，忽视价值传递
2. 定价后从不调整，错失优化机会
3. 忽视平台费用和佣金成本
4. 恶意低价竞争，破坏市场生态
