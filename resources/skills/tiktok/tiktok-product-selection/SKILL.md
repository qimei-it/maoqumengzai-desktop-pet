# TikTok 选品策略与分析

## 选品核心原则

### 5大黄金法则

1. **用户第一**: 研究目标用户需求，TikTok用户以18-35岁年轻群体为主
2. **实惠平价**: 70%商品价格在$9.9-$44.99区间转化最佳
3. **独特性强**: 新奇有趣、视觉冲击力强的产品更易爆单
4. **市场潜力**: 选择需求增长快、竞争不太激烈的品类
5. **利润空间**: 毛利率建议>50%，确保有推广空间

## 利润计算模型

### 成本构成

```
总成本 = 采购成本 + 物流成本 + 平台佣金 + 广告成本 + 退换货成本

采购成本: 工厂出货价
物流成本: 国际运费 + 清关费用
平台佣金: 5-10%（不同市场不同）
广告成本: 按实际投放计算
退换货成本: 预估3-5%
```

### 利润计算公式

```
毛利率 = (售价 - 总成本) / 售价 × 100%

建议毛利率: >50%
最低毛利率: >30%（保证盈利空间）
```
