# TikTok 选品利润计算指南

## 利润计算公式

### 基础公式

```
毛利润 = 售价 - 采购成本 - 物流成本 - 平台佣金 - 支付手续费

毛利率 = 毛利润 / 售价 × 100%

净利润 = 毛利润 - 广告成本 - 退货损耗 - 其他成本
```

---

## 成本构成详解

### 1. 采购成本

| 项目 | 说明 |
|------|------|
| 产品单价 | 工厂出货价 |
| 起订量 | MOQ，影响单价 |
| 样品费 | 首次采购前打样 |
| 定制费 | LOGO、包装定制 |

### 2. 物流成本

**头程运费**（国内到海外仓）:
```
头程运费 = 产品重量 × 单价 + 燃油附加费
```

**尾程运费**（海外仓到客户）:
```
尾程运费 = 首重费用 + (总重量 - 首重) × 续重单价
```

**关税**:
```
关税 = 申报价值 × 关税率
```

### 3. 平台费用

| 平台 | 佣金率 | 支付手续费 |
|------|--------|-----------|
| TikTok Shop US | 1.8% - 8% | 2.9% + $0.30 |
| TikTok Shop UK | 4% - 8% | 2.9% + £0.30 |
| TikTok Shop SEA | 3% - 6% | 2% - 4% |

### 4. 达人佣金

| 粉丝量级 | 佣金率 |
|---------|--------|
| 1-10 万 | 15% - 25% |
| 10-50 万 | 12% - 20% |
| 50-100 万 | 10% - 15% |
| 100 万 + | 8% - 12% |

### 5. 广告成本

```
广告成本 = 曝光量 × CPM / 1000
或
广告成本 = 销量 × CPA
```

| 广告类型 | 平均 CPP/CPA |
|---------|-----------|
| 信息流广告 | $10 - $20 |
| 达人合作 | $5 - $15 |
| 直播带货 | 销售额的 10% - 20% |

### 6. 其他成本

| 项目 | 预估比例 |
|------|---------|
| 退货损耗 | 3% - 8% |
| 仓储费 | $0.5 - $2/件/月 |
| 包装费 | $0.2 - $1/件 |
| 客服成本 | 1% - 2% |

## 利润计算示例

### 示例 1：美妆产品

**产品信息**:
- 产品：精华液 30ml
- 采购成本：$8
- 重量：0.2kg

**定价**: $39.99

**成本计算**:
| 项目 | 金额 |
|------|------|
| 采购成本 | $8.00 |
| 头程运费 | $1.50 |
| 尾程运费 | $4.50 |
| 平台佣金 (8%) | $3.20 |
| 支付手续费 | $1.46 |
| 达人佣金 (20%) | $8.00 |
| 广告成本 | $5.00 |
| **总成本** | $31.66 |

**利润**:
- 毛利润 = $39.99 - $31.66 = $8.33
- 毛利率 = $8.33 / $39.99 = 20.8%

## 盈亏平衡点计算

### 公式

```
盈亏平衡销量 = 固定成本 / (单价 - 单位变动成本)
```

### 示例

**固定成本**:
- 仓储费：$500/月
- 人工：$2000/月
- 软件工具：$200/月
- **合计**: $2700/月

**单位变动成本**:
- 采购 + 物流 + 佣金 = $18

**单价**: $35

```
盈亏平衡销量 = $2700 / ($35 - $18) = 159 件/月
```

## 定价策略

### 成本加成定价

```
售价 = 成本 × (1 + 目标利润率)
```

推荐倍率:
| 类目 | 建议倍率 |
|------|---------|
| 美妆个护 | 4 - 6 倍 |
| 服饰配饰 | 3 - 5 倍 |
| 家居百货 | 3 - 4 倍 |
| 3C 数码 | 2 - 3 倍 |

### 竞争定价

参考竞品价格，设置:
- 市场渗透价：竞品价 × 0.8 - 0.9
- 市场跟随价：竞品价 × 0.95 - 1.05
- 市场领导价：竞品价 × 1.1 - 1.3（需有差异化优势）

### 心理定价

- 尾数定价：$29.99 vs $30
- 锚定定价：原价 ~~$59~~ 现价 $39
- 阶梯定价：1 件$25 / 2 件$45 / 3 件$60

## 利润优化建议

### 降低成本
1. **采购成本**: 量大议价、寻找源头工厂
2. **物流成本**: 优化包装、选择性价比物流
3. **平台佣金**: 选择低佣金类目
4. **广告成本**: 优化素材、提高转化率

### 提高售价
1. **品牌溢价**: 打造品牌形象
2. **差异化**: 独特设计、功能
3. **增值服务**: 延保、定制
4. **套装销售**: 组合提高客单价
