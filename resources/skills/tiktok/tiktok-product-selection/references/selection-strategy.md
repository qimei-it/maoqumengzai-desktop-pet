# TikTok 选品策略参考

## 选品核心原则

### 三个匹配
```
【人与货匹配】
达人粉丝画像 × 产品目标用户 = 重合度

【价与值匹配】
产品质量 × 产品价格 = 性价比

【时与势匹配】
产品属性 × 当前趋势 = 爆款潜力
```

### 选品公式
```
爆款潜力 = (市场需求 × 产品差异化 × 供应链能力) / 竞争度
```

---

## 爆款品类特征

### 高潜质品类
| 品类 | 特点 | 定价策略 |
|------|------|---------|
| 美妆护肤 | 复购率高、利润高 | 中高价位 |
| 新奇特产品 | 新鲜感强 | 中价位 |
| 日用品 | 刚需、消耗品 | 低价走量 |
| 食品零食 | 尝鲜冲动 | 低价尝鲜 |

### 避坑品类
- 品质难控的产品
- 售后复杂的产品
- 争议性产品
- 运输易损产品
- 季节性过强产品

## 达人选品要点

### 选品清单
- [ ] 产品与我领域相关
- [ ] 质量经过验证
- [ ] 价格有竞争力
- [ ] 供应链稳定
- [ ] 售后有保障

### 测款流程
```
【初次测试】
├─ 小批量测试
├─ 观察数据反馈
├─ 收集用户评价
└─ 决定是否深入

【放量推广】
├─ 确认数据良好
├─ 加大投入
├─ 优化内容
└─ 持续追踪
```

## 供应商管理

### 供应商评估
| 维度 | 考核点 |
|------|--------|
| 产品质量 | 样品检测、用户反馈 |
| 发货能力 | 库存充足、发货及时 |
| 价格优势 | 批发价有竞争力 |
| 合作态度 | 配合度、沟通顺畅 |
| 售后支持 | 退换货处理 |

### 合作谈判要点
- 争取更低批发价
- 确认库存量
- 约定发货时效
- 明确退换货政策
- 争取账期支持
