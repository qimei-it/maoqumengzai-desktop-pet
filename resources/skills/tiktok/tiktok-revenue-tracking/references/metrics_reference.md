# TikTok Revenue Tracking - Metrics Reference

## 核心指标定义

### 达人侧指标

#### 收入指标
| 指标 | 公式 | 说明 |
|------|------|------|
| 总收入 | Σ 各渠道收入 | 所有收入来源总和 |
| 月均收入 | 总收入 / 月数 | 平均每月收入 |
| 日均收入 | 月收入 / 当月天数 | 平均每日收入 |
| 收入中位数 | 排序后中间值 | 收入的典型水平 |
| 收入峰值 | max(月收入) | 最高单月收入 |

#### 增长指标
| 指标 | 公式 | 说明 |
|------|------|------|
| MoM 增长率 | (本月-上月)/上月 × 100% | 环比增长 |
| YoY 增长率 | (今年-去年)/去年 × 100% | 同比增长 |
| 平均增长率 | CAGR | 复合年增长率 |
| 增长稳定性 | 收入标准差 / 平均收入 | 波动程度 |

#### 结构指标
| 指标 | 公式 | 说明 |
|------|------|------|
| 商单收入占比 | 商单收入 / 总收入 | 收入结构健康度 |
| 带货收入占比 | 带货佣金 / 总收入 | 变现能力 |
| 广告收入占比 | 广告收入 / 总收入 | 流量价值 |
| 收入集中度 | max(各渠道占比) | 依赖风险 |

---

### 商家侧指标

#### GMV 指标
| 指标 | 公式 | 说明 |
|------|------|------|
| 总 GMV | Σ 各渠道销售额 | 商品交易总额 |
| 自营 GMV | 自营店铺销售额 | 自营销售能力 |
| 达人 GMV | Σ 达人带货销售额 | 达人合作效果 |
| 直播 GMV | 直播间销售额 | 直播带货能力 |
| 广告 GMV | 广告带来的销售额 | 广告投放效果 |

#### 利润指标
| 指标 | 公式 | 说明 |
|------|------|------|
| 毛利 | GMV - 商品成本 | 毛利润额 |
| 净利 | 毛利 - 佣金 - 广告费 - 物流 | 净利润额 |
| 毛利率 | 毛利 / GMV × 100% | 毛利水平 |
| 净利率 | 净利 / GMV × 100% | 净利水平 |

#### ROI 指标
| 指标 | 公式 | 说明 |
|------|------|------|
| 广告 ROI | (销售额-总成本)/广告费 | 广告投放效率 |
| 达人 ROI | 净利 / (佣金+样品) | 达人合作效率 |
| 综合ROI | 总利润 / 总投入 | 整体效率 |

## 分析维度

### 时间维度
- **日度**: 实时监控，短期波动
- **周度**: 趋势分析，活动效果
- **月度**: 常规分析，业绩考核
- **季度**: 战略分析，目标调整
- **年度**: 长期规划，增长评估

### 渠道维度
- **自营**: 直接销售能力
- **达人**: 合作效果评估
- **直播**: 实时带货能力
- **广告**: 流量获取效率

### 品类维度
- **高毛利**: 美妆、服饰
- **高周转**: 食品、日用品
- **高客单**: 3C、家电

## 预警阈值

### 红色预警（立即处理）
| 指标 | 阈值 | 说明 |
|------|------|------|
| ROI | <1.0 | 亏损状态 |
| 月收入下降 | >20% | 显著下滑 |
| 单一渠道占比 | >80% | 风险集中 |

### 橙色预警（关注优化）
| 指标 | 阈值 | 说明 |
|------|------|------|
| ROI | 1.0-1.5 | 利润微薄 |
| 月收入下降 | 10-20% | 需要关注 |
| 单一渠道占比 | 70-80% | 风险较高 |

### 黄色预警（持续观察）
| 指标 | 阈值 | 说明 |
|------|------|------|
| ROI | 1.5-2.0 | 有提升空间 |
| 月收入增长 | 0-5% | 增长缓慢 |
| 单一渠道占比 | 60-70% | 适度集中 |

## 计算示例

### 达人收入计算
```python
# 场景: 50万粉丝美妆达人
# 商单报价: ¥22,000 (CPM ¥550)
# 带货佣金: 20% 佣金率，带货GMV ¥80,000
# 广告收入: ¥8,000 (创作者基金)

总收入 = 22000 + (80000 * 0.2) + 80000
      = 22000 + 16000 + 80000
      = ¥46,000

收入结构:
  商单: 47.8%
  带货: 34.8%
  广告: 17.4%
```

### 商家 ROI 计算
```python
# 场景: 广告投放 ¥10,000
# 带来销售额 ¥45,000
# 产品成本 40%

成本 = 10000 + (45000 * 0.4)
    = 10000 + 18000
    = ¥28,000

利润 = 45000 - 28000 = ¥17,000

ROI = 17000 / 10000 = 1.7 (170%)

评估: 低于广告投放基准(2.0)，需优化
```
