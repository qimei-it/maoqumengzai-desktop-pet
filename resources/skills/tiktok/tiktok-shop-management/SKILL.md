# TikTok 店铺管理

## Seller Center后台

### 核心功能模块

| 模块 | 功能 |
|------|------|
| 商品管理 | 上架、编辑、下架商品 |
| 订单管理 | 订单处理、发货、售后 |
| 数据中心 | 销售数据、流量分析 |
| 营销中心 | 优惠券、活动、推广 |
| 财务中心 | 结算、账单、提现 |

## 订单管理

### 订单状态流程

```
买家下单 → 待付款 → 已付款(待发货) → 已发货 → 已送达 → 已完成
                                    ↓
                              取消/退款
```

### 订单处理时效

| 状态 | 时限要求 | 操作 |
|------|----------|------|
| 待付款 | 48小时 | 等待买家付款 |
| 待发货 | 48小时 | 打包发货 |
| 已发货 | 5-15天 | 等待签收 |
| 已送达 | 7天 | 等待确认 |

### 发货流程

1. 确认订单信息
2. 打印面单
3. 打包商品
4. 贴单发货
5. 上传物流单号
6. 更新订单状态

## 客服管理

### 客服工具

| 工具 | 功能 | 响应时间 |
|------|------|----------|
| IM聊天 | 即时沟通 | <12小时 |
| 邮件 | 复杂问题 | <24小时 |
| 自动回复 | 常见问题 | 即时 |

### 常见问题回复模板

**物流查询**:
```
您好！感谢您的耐心等待。您的订单已发货，
物流单号：XXX
预计送达时间：X-X天
如有问题请随时联系我们。
```

**退款处理**:
```
您好！您的退款申请已收到。
我们将在X个工作日内处理完毕。
退款将原路返回到您的支付账户。
如有疑问请联系我们。
```

**产品质量**:
```
抱歉给您带来不好的体验！
请您提供产品照片/视频，我们核实后将为您：
1. 免费补发
2. 全额退款
3. 换货处理
请您选择合适的处理方式。
```

### 客服要点

- 响应及时（<12小时）
- 态度友好
- 解决问题为主
- 避免纠纷升级

## 售后处理

### 退款原因分析

| 原因 | 占比 | 处理建议 |
|------|------|----------|
| 物流问题 | 30% | 选择可靠物流 |
| 产品质量问题 | 25% | 严格质检 |
| 尺码不符 | 20% | 完善尺码指南 |
| 描述不符 | 15% | 准确描述 |
| 其他 | 10% | 沟通解决 |

### 退换货流程

```
买家申请 → 卖家审核 → 同意/拒绝
    ↓
同意 → 买家寄回 → 卖家收货 → 退款/换货
    ↓
拒绝 → 平台介入
```

### 纠纷处理

**避免纠纷**:
- 产品描述准确
- 图片真实清晰
- 尺码指南详细
- 发货前质检

**处理纠纷**:
- 积极沟通
- 快速响应
- 合理补偿
- 必要时平台介入

## 评价管理

### 评价类型

| 评分 | 影响 | 应对 |
|------|------|------|
| 5星 | 正面 | 感谢、引导晒图 |
| 4星 | 较好 | 了解改进点 |
| 3星 | 中性 | 主动沟通 |
| 1-2星 | 负面 | 及时处理、争取修改 |

### 提升评价方法

1. **产品质量**: 严把质量关
2. **描述准确**: 不夸大宣传
3. **物流时效**: 快速发货
4. **客服服务**: 快速响应
5. **售后保障**: 无忧退换

### 差评处理

```
1. 及时发现差评
2. 分析差评原因
3. 联系买家沟通
4. 提供解决方案
5. 请求修改评价（如满意）
```

## 库存管理

### 库存预警

| 状态 | 库存天数 | 操作 |
|------|----------|------|
| 充足 | >30天 | 正常销售 |
| 需关注 | 15-30天 | 准备补货 |
| 预警 | 7-15天 | 立即补货 |
| 紧急 | <7天 | 紧急补货/下架 |

### 补货策略

- 安全库存 = 日销量 × 补货周期 × 1.5
- 补货点 = 安全库存 + 日销量 × 物流时间
- 补货量 = (日销量 × 销售周期) - 当前库存
