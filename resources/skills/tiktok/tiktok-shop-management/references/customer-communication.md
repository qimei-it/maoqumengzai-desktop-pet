# TikTok 客服话术手册

## 一、售前咨询

### 1.1 开场白模板

**标准开场**:
```
您好！欢迎光临 [店铺名称] 😊
请问有什么可以帮您的吗？
```

**活动引导**:
```
您好！我们现在有 [活动名称]，全场满$50 减$10
请问您对哪款产品感兴趣呢？
```

### 1.2 产品咨询回复

**产品参数询问**:
```
您好！这款产品的详细参数如下：

📦 规格：[规格信息]
🎨 颜色：[颜色选项]
📏 尺寸：[尺寸详情]
⚖️ 重量：[重量信息]
📄 材质：[材质说明]

如有其他疑问，请随时告诉我！
```

**产品功效询问**:
```
您好！这款产品的主要功效是：

✅ [功效 1]
✅ [功效 2]
✅ [功效 3]

[可选] 这是客户使用后的反馈，您可以参考一下：
[用户评价截图/视频]

您还有什么想了解的吗？
```

**库存询问**:
```
您好！您咨询的这款产品目前有现货的～
✅ [颜色/规格 1] - 有货
✅ [颜色/规格 2] - 有货
❌ [颜色/规格 3] - 暂时缺货，预计 X 月 X 日到货

您想订购哪个规格呢？
```

## 二、售中跟进

📦 商品：[商品名称]
🎨 颜色：[颜色]
📍 地址：[收货地址]

请您核对一下信息是否正确，确认后我们尽快为您安排发货～
```

**付款提醒**:
```

现在付款可以享受：
🎁 今日发货
🎁 赠品：[赠品名称]
🎁 优惠券：[优惠金额]

活动限时 [X] 小时，不要错过哦！

请您提供新的地址信息：
📍 收件人：

**修改规格**:

## 三、物流咨询

### 3.1 发货时效

**发货时间询问**:
```
您好！我们的发货时效是：

⏰ 付款后 48 小时内发货
⏰ 订单在 [具体时间] 前付款，当天发货

您这边已经下单成功，预计 [日期] 前为您发出～
```

**物流时效询问**:
```
您好！物流时效参考：

🚚 同城/邻近地区：1-3 个工作日
🚚 省内：2-4 个工作日
🚚 跨省：3-7 个工作日
🚚 偏远地区：7-10 个工作日

具体以物流公司实际派送为准哦～
```

### 3.2 物流异常处理

**物流停滞**:
```
您好！非常抱歉给您带来不好的体验。😔

我已经帮您查询了物流信息，目前包裹在 [地点]。
我已经联系物流公司催促，预计 1-2 个工作日会有更新。

我会持续跟进，一有消息立即通知您！
```

**包裹丢失**:
```
您好！非常抱歉发生这种情况。😔

经核实，您的包裹在运输过程中丢失了。

我们可以为您：
🔄 免费补发一份
💰 或者全额退款

您看哪种方式更方便呢？
```

## 四、售后处理

### 4.1 退换货处理

**换货流程**:
```
您好！很抱歉产品有问题给您带来不便。😔

为您办理换货流程如下：

1️⃣ 您将商品寄回（地址：[退货地址]）
2️⃣ 我们收到后 24 小时内发出新品
3️⃣ 新物流单号：[单号]

退货运费由我们承担，请您先垫付，收货后退还给您。
您看可以吗？
```

**退款流程**:
```
您好！已收到您的退款申请。

处理流程：
✅ 申请已提交
⏳ 等待商家审核（1-2 个工作日）
💰 审核通过后原路退款

退款到账时间：3-7 个工作日
```

### 4.2 质量问题

**产品损坏**:
```
您好！非常抱歉收到损坏的产品！😔

请您拍照发给我们看一下损坏情况，我们核实后立即为您处理。

处理方式：
🔄 免费补发
💰 或者全额退款

您选择哪种呢？
```

**产品瑕疵**:
```
您好！很抱歉产品有瑕疵问题。

为了表示歉意，我们为您准备：
🎁 全额退款（产品不用退回）
🎁 或者补发新品 + $5 优惠券

您看哪种方案您更满意？
```

### 4.3 不满意处理

**效果不满意**:
```
您好！很抱歉产品没有达到您的期望。😔

如果您想退货，我们支持 7 天无理由退换：
📦 产品未拆封使用：可全额退款
📦 产品已拆封：可部分退款 [比例]

您看可以吗？
```

## 五、评价管理

### 5.1 好评邀请

**发货后邀请**:
```
您好！您的宝贝已经发货啦～📦

预计 [日期] 送达，请您注意查收。

收到后如果满意，麻烦给我们一个五星好评⭐⭐⭐⭐⭐
您的支持对我们非常重要！
```

**签收后跟进**:
```
您好！看到您已经签收了商品～

请问产品还满意吗？
如果有任何问题请随时联系我们，我们一定帮您妥善解决！

😃 如果满意的话，方便给我们一个好评吗？
好评截图联系客服可以领取$3 优惠券哦～
```

### 5.2 差评处理

**差评首次回复**:
```
您好！看到您的评价我们非常重视。😔

非常抱歉给您带来不好的体验！我们已经收到您的反馈，请给我们一个机会弥补过错。

客服将在 24 小时内与您联系，为您妥善处理！
```

**私信沟通**:
```
您好！我是店铺客服 [名字]。

看到您对我们的产品不太满意，非常抱歉！😔

请问具体是什么问题呢？
📦 物流问题？
📦 产品质量？
📦 产品不会使用？

告诉我具体情况，我一定帮您妥善解决！
```

### 5.3 改评价请求

**问题解决后**:
```
您好！之前的问题已经为您处理完毕。

🔄 补发的商品已收到吗？
💰 退款已到账，请查收。

如果您对我们的处理满意，方便帮我修改一下评价吗？🙏

这对我们小店非常重要，非常感谢您的理解和支持！
```

## 六、投诉处理

### 6.1 投诉应对原则

**处理流程**:
```
1. 耐心倾听，不打断
2. 表示理解和歉意
3. 确认问题细节
4. 提出解决方案
5. 跟进处理结果
6. 事后回访
```

### 6.2 投诉话术

**情绪安抚**:
```
您好！非常理解您的心情，发生这样的事确实让人很不开心。😔

请您放心，我们一定会负责到底！

请您给我 2 分钟，我立即核实具体情况...
```

**解决方案**:
```
您好！问题已经核实清楚了。

这次确实是我们工作不到位，非常抱歉！😔

为了弥补我们的过失，我们为您准备：
[具体方案]

您看这样可以吗？如果还有其他要求，请告诉我。
```
