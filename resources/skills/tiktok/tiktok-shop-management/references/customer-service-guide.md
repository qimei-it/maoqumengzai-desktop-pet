# TikTok 店铺客服指南

## 客服工作流程

### 标准流程

```
客户咨询 → 问题识别 → 解答处理 → 确认满意 → 记录归档
```

---

## 常见问题处理

### 物流咨询

**客户**: "我的快递到哪了？"

**回复模板**:
```
亲亲您好~ 帮您查询了一下，您的包裹目前已经到达【XX 转运中心】，
预计 1-2 天内就能送达哦~ 请您保持电话畅通，快递员会联系您的 📦✨
```

**处理步骤**:
1. 查询物流状态
2. 告知客户最新进度
3. 预计送达时间
4. 提醒保持电话畅通

---

### 退换货咨询

**客户**: "怎么退货？"

**回复模板**:
```
亲亲您好~ 我们支持 7 天无理由退换货的哦 😊

退货流程:
1. 在订单页面点击"申请售后"
2. 选择"退货退款"
3. 填写退货原因
4. 系统将提供退货地址
5. 寄回后填写单号即可

注意：商品需保持完好未使用状态哦~
```

---

### 产品质量问题

**客户**: "收到货发现有质量问题"

**回复模板**:
```
非常抱歉给您带来不好的体验 😔 质量问题我们一定会负责的！

请您拍一下产品问题的照片发给我们，确认后我们会：
1. 为您安排免费换货
2. 或者全额退款（包含运费）

您看这样可以吗？再次为给您带来的不便道歉 🙏
```

**处理步骤**:
1. 道歉并安抚情绪
2. 要求提供问题照片
3. 确认问题后给出方案
4. 承担往返运费

## 客服话术技巧

### 开头称呼

| 称呼 | 适用场景 |
|------|---------|
| 亲亲/宝子 | 通用，年轻用户 |
| 您好 | 正式场合 |
| 小姐姐/小哥哥 | 轻松互动 |

### 语气词使用

**推荐**:
- 哦~ 呢~ 哈~（增加亲和力）
- 😊 ✨ 🎁 📦（适当 emoji）

**避免**:
- 过于正式的书面语
- 冷淡的回复
