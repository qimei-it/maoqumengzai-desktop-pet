## 纠纷处理流程

### 标准流程

```
收到纠纷 → 了解情况 → 核实证据 → 提出方案 → 协商沟通 → 达成和解
```

### 处理时效

| 阶段 | 时效要求 |
|------|---------|
| 响应纠纷 | 24 小时内 |
| 提供证据 | 3 个工作日内 |
| 协商处理 | 5 个工作日内 |
| 平台介入 | 7 个工作日后 |

## 各类纠纷处理

### 1. 物流纠纷

**常见原因**:
- 物流太慢
- 包裹丢失
- 包裹破损
- 未收到货

**处理方案**:

| 情况 | 方案 |
|------|------|
| 物流停滞 | 催物流商 + 适当补偿 |
| 包裹丢失 | 补发或退款 + 小礼品 |
| 包裹破损 | 拍照确认 + 补发/退款 |
| 未收到货 | 核实签收情况 + 解决方案 |

**回复模板**:
```
非常抱歉给您带来不好的体验 😔 物流问题我们一定会帮您解决！

我们已经联系快递公司核实情况，预计 1-2 天内给您回复。
如果确认丢失，我们会立即为您补发/退款。

为表歉意，送您一张¥5 优惠券，期待您的谅解 🙏
```

---

### 2. 质量纠纷

**常见原因**:
- 产品损坏
- 功能异常
- 材质问题
- 做工瑕疵

**处理流程**:

```
1. 要求客户提供问题照片/视频
2. 核实问题严重程度
3. 提出解决方案（换货/退款/补偿）
4. 客户确认后执行
5. 跟进至问题闭环
```

**处理方案**:

| 问题程度 | 方案 |
|---------|------|
| 轻微瑕疵 | 补偿¥5-10 + 道歉 |
| 功能问题 | 免费换货或退款 |
| 严重损坏 | 退款 + 承担运费 |

---

### 3. 描述不符纠纷

**常见原因**:
- 颜色差异
- 尺寸偏差
- 功能描述夸大
- 图片与实物不符

**预防措施**:

| 措施 | 说明 |
|------|------|
| 实物拍摄 | 避免过度美化 |
| 详细参数 | 标注尺寸、颜色等 |
| 色差说明 | 提前告知可能有色差 |
| 买家秀 | 展示真实评价 |

**处理方案**:
```
1. 道歉并承认描述不当
2. 提供退换货服务
3. 承担往返运费
4. 适当补偿
```

---

### 4. 退款纠纷

**常见原因**:
- 退款申请被拒
- 退款金额有异
- 退款时间太长

**处理流程**:

```
1. 核实退款原因
2. 检查退回商品
3. 确认退款金额
4. 及时打款
```

**退款时效**:

| 阶段 | 时效 |
|------|------|
| 买家申请 | - |
| 卖家响应 | 48 小时内 |
| 买家寄回 | 7 天内 |
| 卖家收货确认 | 48 小时内 |
| 退款到账 | 1-3 个工作日 |

## 平台介入处理

### 平台介入条件

满足以下情况平台会介入:
1. 买卖双方协商不成
2. 卖家超时未处理
3. 买家申请平台介入

### 平台裁决依据

| 依据 | 权重 |
|------|------|
| 聊天记录 | 高 |
| 商品照片 | 高 |
| 物流信息 | 中 |
| 买家评价 | 中 |
| 卖家描述 | 低 |

### 避免平台介入

**建议**:
- 及时响应纠纷
- 积极协商解决方案
- 保留完整证据
- 必要时适当让步

---

## 纠纷预防

### 售前预防

| 措施 | 说明 |
|------|------|
| 详实描述 | 产品信息准确完整 |
| 实物拍摄 | 避免过度美化 |
| 告知风险 | 提前说明可能的问题 |
| 设置预期 | 物流时效说明 |

### 售后预防

| 措施 | 说明 |
|------|------|
| 及时发货 | 48 小时内发货 |
| 物流追踪 | 异常及时处理 |
| 主动沟通 | 问题提前告知 |
| 满意回访 | 确认客户满意 |
