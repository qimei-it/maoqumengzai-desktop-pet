# TikTok 店铺订单处理流程

## 订单处理流程

### 标准流程

```
订单生成 → 订单审核 → 打单配货 → 打包发货 → 物流追踪 → 签收完成
```

---

## 订单审核

### 审核要点

| 检查项 | 说明 |
|------|------|
| 收货地址 | 是否完整、准确 |
| 联系方式 | 电话是否有效 |
| 订单金额 | 是否有异常 |
| 买家信用 | 是否有风险记录 |
| 库存状态 | 是否有货 |

### 风险订单识别

**高风险特征**:
- 收货地址模糊或不完整
- 联系电话无法接通
- 同一地址多笔订单
- 新账号大额订单
- 要求修改收货地址

**处理方式**:
1. 电话确认订单
2. 要求买家验证身份
3. 延迟发货等待确认
4. 必要时取消订单

---

## 打单配货

### 打印单据

**必需单据**:
- 发货单/拣货单
- 快递面单
- 发票（如需要）
- 售后卡

### 拣货流程

```
1. 根据拣货单到仓库拣货
2. 扫描商品条码核对
3. 检查商品质量和有效期
4. 放入待打包区
```

### 配货检查

| 检查项 | 方法 |
|------|------|
| 商品 SKU | 扫描条码核对 |
| 商品数量 | 人工点数 |
| 商品质量 | 外观检查 |
| 有效期 | 检查生产日期 |

---

## 打包规范

### 包装材料

| 材料 | 用途 |
|------|------|
| 纸箱/快递袋 | 外包装 |
| 气泡膜 | 防震保护 |
| 填充物 | 空隙填充 |
| 胶带 | 封口 |
| 贴纸 | 标识 |

### 打包步骤

```
1. 商品包裹气泡膜
2. 放入合适尺寸纸箱
3. 填充空隙
4. 封箱贴面单
5. 称重记录
```

### 打包注意事项

**必须做**:
- ✅ 易碎品加强保护
- ✅ 液体防漏处理
- ✅ 贵重物品保价
- ✅ 放入感谢卡/售后卡

**避免做**:
- ❌ 包装过大浪费运费
- ❌ 包装过小保护不足
- ❌ 忘记放发货单
- ❌ 面单贴歪或被遮盖

---

## 发货流程

### 发货时效

| 订单类型 | 要求时效 |
|---------|---------|
| 普通订单 | 48 小时内 |
| 预售订单 | 按约定时间 |
| 加急订单 | 24 小时内 |

### 物流商选择

**选择因素**:
- 价格
- 时效
- 覆盖范围
- 服务质量
- 理赔政策

### 发货操作

```
1. 在 TikTok 后台点击发货
2. 填写/扫描快递单号
3. 系统同步物流信息
4. 买家收到发货通知
```

---

## 物流追踪

### 追踪节点

| 节点 | 说明 |
|------|------|
| 已收件 | 快递已揽收 |
| 运输中 | 在途中转运 |
| 到达网点 | 到达目的地 |
| 派送中 | 正在派送 |
| 已签收 | 客户已签收 |

### 异常处理

| 异常类型 | 处理方式 |
|---------|---------|
| 物流停滞 | 联系物流商查询 |
| 派送失败 | 联系买家确认地址 |
| 包裹丢失 | 申请理赔 + 补发 |
| 包裹破损 | 申请理赔 + 补发/退款 |
