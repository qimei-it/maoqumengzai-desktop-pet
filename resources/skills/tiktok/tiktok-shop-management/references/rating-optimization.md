# TikTok 店铺评分优化指南

## 评分体系

### 评分构成

TikTok Shop 店铺评分由以下部分组成：

| 指标 | 权重 | 说明 |
|------|------|------|
| 商品评分 | 40% | 商品质量、描述符合度 |
| 物流评分 | 30% | 发货速度、物流服务 |
| 服务评分 | 30% | 客服响应、售后服务 |

### 评分等级

| 分数 | 等级 | 影响 |
|------|------|------|
| 4.8-5.0 | 优秀 | 流量倾斜、活动优先 |
| 4.5-4.8 | 良好 | 正常运营 |
| 4.0-4.5 | 一般 | 流量受限 |
| < 4.0 | 较差 | 可能被限流/下架 |

---

## 评分提升策略

### 商品评分提升

**核心要素**:
1. **商品质量**
   - 严格质检
   - 选择可靠供应商
   - 定期抽检

2. **描述准确**
   - 实物拍摄
   - 参数详细准确
   - 避免夸大宣传

3. **包装完好**
   - 加强包装保护
   - 防震防漏处理
   - 附带感谢卡

---

### 物流评分提升

**发货速度**:

| 目标 | 措施 |
|------|------|
| 24 小时内发货 | 现货充足、快速响应 |
| 48 小时内发货 | 标准时效 |
| 避免超时 | 及时下架缺货商品 |

**物流选择**:
- 选择可靠物流商
- 提供物流追踪
- 异常主动沟通

**包装体验**:
- 精美包装
- 防损保护
- 开箱体验

---

### 服务评分提升

**客服响应**:

| 指标 | 目标 |
|------|------|
| 首次响应 | < 2 分钟 |
| 平均响应 | < 5 分钟 |
| 解决率 | > 90% |

**服务态度**:
- 热情友好
- 耐心解答
- 主动跟进

**售后保障**:
- 7 天无理由退换
- 质量问题包退换
- 运费险

## 好评获取技巧

### 主动索评

**时机选择**:
- 客户签收后 3-5 天
- 确认客户满意后
- 售后问题解决后

**索评话术**:
```
亲亲~ 您的宝贝应该已经收到了吧？
如果满意的话，麻烦给个 5 星好评哦 ⭐⭐⭐⭐⭐
晒图评价还有红包奖励呢 🎁
感谢您的支持~
```

### 好评激励

| 激励方式 | 成本 | 效果 |
|---------|------|------|
| 评价返现 | ¥1-3/条 | ⭐⭐⭐⭐ |
| 优惠券 | ¥3-5 | ⭐⭐⭐ |
| 抽奖活动 | 低成本 | ⭐⭐⭐ |
| 会员积分 | 低成本 | ⭐⭐ |

**注意事项**:
- 避免直接说"好评返现"
- 使用"晒图奖励"等表述
- 遵守平台规则

## 差评处理

### 差评预防

| 措施 | 说明 |
|------|------|
| 售前沟通 | 确认需求、降低预期 |
| 售中跟进 | 物流异常及时通知 |
| 售后保障 | 问题快速解决 |

### 差评挽回

**发现差评后**:

```
1. 第一时间回复（2 小时内）
2. 私信联系客户了解原因
3. 提出解决方案
4. 请求修改评价（如满意）
```

**公开回复模板**:
```
非常抱歉给您带来不好的体验 😔
我们已私信您，会尽快为您解决问题！
如有任何问题，请随时联系我们~
```

**私信挽回话术**:
```
亲亲您好~ 看到您的评价我们很難过 😢
能告诉我们具体是什么问题吗？
我们一定会帮您解决到满意为止！
```

### 差评移除

**可移除情况**:
- 恶意差评（同行攻击）
- 广告/垃圾信息
- 与商品无关内容
- 泄露个人信息

**申诉流程**:
1. 收集证据（聊天记录等）
2. 在后台提交申诉
3. 等待平台审核
4. 审核通过则删除

**预警阈值**:

- 评分<4.5 分 → 紧急处理
