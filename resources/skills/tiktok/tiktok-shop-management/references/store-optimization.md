# TikTok 店铺运营参考

## 商品上架优化

### 主图优化
```
【第一张主图】
├─ 产品正面清晰图
├─ 吸引眼球的设计元素
└─ 价格/优惠信息

【后续图片】
├─ 细节特写 (2-3张)
├─ 使用场景 (2-3张)
├─ 对比展示 (1张)
└─ 包装/配件 (1张)
```

### 标题公式
```
【利益型】
"xxx让你轻松yyy！"

【痛点型】
"还在为yyy烦恼？xxx帮你解决！"

【场景型】
"yyy场景必备，xxx效果惊艳！"
```

### 详情页结构
1. **痛点场景**: 用户遇到的问题
2. **产品介绍**: 解决方案展示
3. **使用方法**: 怎么用更有效
4. **效果证明**: 对比/用户反馈
5. **规格参数**: 规格选项
6. **购买保障**: 售后承诺

## 促销活动设计

### 常见促销类型
| 类型 | 折扣力度 | 适用场景 |
|------|---------|---------|
| 限时秒杀 | 5-7折 | 新品引流 |
| 满减优惠 | 实质优惠 | 提高客单价 |
| 买赠活动 | 心理优惠 | 库存清理 |
| 组合套装 | 15-25% off | 提升连带率 |

### 活动节奏
```
日常: 小幅优惠，维持关注
周末: 中等活动，促进转化
大促: 大幅优惠，冲量销售
节日: 主题营销，情感共鸣
```
