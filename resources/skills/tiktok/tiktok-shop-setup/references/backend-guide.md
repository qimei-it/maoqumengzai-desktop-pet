## 二、商品管理

### 2.1 发布新商品

**操作路径**: 商品 → 添加商品

**发布步骤**:

```
步骤 1：选择发布方式
├─ 单个发布（适合少量商品）
├─ 批量发布（Excel 导入）
└─ API 发布（ERP 系统对接）

步骤 2：填写基本信息
├─ 商品名称（≤200 字符）
├─ 商品类目（选择最精准的一级类目）
├─ 品牌信息（有品牌填品牌，无品牌选"无品牌"）
└─ 商品属性（按实际填写）

步骤 3：上传商品图片
├─ 主图（至少 3 张，建议 5-9 张）
├─ 详情图
└─ 视频（可选，建议上传）

步骤 4：设置 SKU
├─ 规格名称（颜色、尺寸等）
├─ 价格
├─ 库存
└─ SKU 图片

步骤 5：填写商品详情
├─ 商品描述
├─ 规格参数
├─ 使用场景
└─ 售后说明

步骤 6：设置物流
├─ 发货地
├─ 运费模板
└─ 发货时效

步骤 7：提交审核
```

### 2.2 商品编辑

**操作路径**: 商品 → 商品管理 → 选择商品 → 编辑

**可编辑内容**:
- ✅ 商品标题
- ✅ 商品图片
- ✅ 商品价格
- ✅ 商品库存
- ✅ 商品详情
- ❌ 商品类目（一般不可改）

### 2.3 商品上下架

**上架操作**:
```
商品管理 → 选择商品 → 点击「上架」
```

**下架操作**:
```
商品管理 → 选择商品 → 点击「下架」
```

**批量操作**:
```
勾选多个商品 → 批量操作 → 上架/下架
```

## 三、订单管理

### 3.1 查看订单

**操作路径**: 订单 → 订单管理

**筛选条件**:
- 订单状态（待付款/待发货/已发货/已完成）
- 下单时间
- 商品关键词
- 买家信息

### 3.2 订单处理流程

```
1. 查看待发货订单
   ↓
2. 打印快递单
   - 点击「打印面单」
   - 选择打印机
   - 确认打印
   ↓
3. 配货打包
   - 按订单拣货
   - 检查商品质量
   - 打包封装
   ↓
4. 粘贴面单
   - 核对订单信息
   - 粘贴快递单
   ↓
5. 确认发货
   - 扫描/手动输入运单号
   - 点击「确认发货」
   - 系统自动通知买家
```

### 3.3 批量发货

**操作步骤**:
```
1. 订单管理 → 待发货
2. 勾选需要发货的订单
3. 点击「批量发货」
4. 选择物流公司
5. 上传运单号（可 Excel 导入）
6. 确认发货
```

## 四、售后管理

### 4.1 退款/退货申请

**操作路径**: 售后 → 退款/退货

**处理流程**:
```
1. 查看售后申请
   ↓
2. 审核申请原因
   ↓
3. 与买家沟通（可选）
   ↓
4. 做出决定
   ├─ 同意退款
   ├─ 拒绝（需说明理由）
   └─ 要求退货
   ↓
5. 执行决定
```

### 4.2 处理退货

```
买家发起退货申请
    ↓
商家审核（2 天内）
    ↓
同意 → 发送退货地址
    ↓
买家寄回
    ↓
商家收货验货
    ↓
确认退款
```

### 4.3 售后数据统计

**查看路径**: 数据 → 售后数据

**核心指标**:
- 退款率
- 退货率
- 平均处理时长
- 售后原因分布

## 五、客服中心

### 5.1 IM 消息回复

**操作路径**: 客服 → 消息中心

**回复要求**:
- ⏰ 响应时间：< 12 小时
- 📊 回复率：> 90%
- ⭐ 满意度：> 4.5 星

### 5.2 快捷回复设置

**设置路径**: 客服 → 快捷回复 → 添加

**操作步骤**:
```
1. 点击「添加快捷回复」
2. 填写分类（如：物流、产品、售后）
3. 填写问题标题
4. 填写回复内容
5. 保存
```

### 5.3 消息数据

**查看路径**: 客服 → 消息数据

**核心指标**:
- 会话总数
- 平均响应时间
- 满意度评分
- 未回复率

## 六、数据中心

### 6.1 销售数据

**查看路径**: 数据 → 销售数据

**可查看维度**:
- 时间维度（今日/近 7 天/近 30 天/自定义）
- 商品维度（单品销量/品类销量）
- 流量维度（流量来源/转化率）

### 6.2 商品数据

**核心指标**:
- 商品曝光量
- 商品点击率
- 商品转化率
- 商品加购率

**分析应用**:
```
高曝光、低点击 → 优化主图/价格
高点击、低转化 → 优化详情页/评价
高加购、低支付 → 优化价格/运费
```

### 6.3 流量数据

**流量来源**:
- 推荐页
- 搜索
- 店铺页
- 直播
- 短视频
- 站外

## 七、营销中心

### 7.1 创建优惠券

**操作路径**: 营销 → 优惠券 → 创建

**优惠券类型**:
| 类型 | 说明 | 适用场景 |
|------|------|---------|
| 关注券 | 关注店铺可领 | 增加粉丝 |
| 无门槛券 | 无消费门槛 | 拉新转化 |
| 满减券 | 满 X 减 Y | 提高客单价 |
| 商品券 | 指定商品可用 | 单品促销 |

**创建步骤**:
```
1. 选择优惠券类型
2. 设置优惠金额
3. 设置使用条件
4. 设置发放数量
5. 设置有效期
6. 选择适用商品
7. 提交发布
```

### 7.2 报名平台活动

**操作路径**: 营销 → 平台活动

**活动类型**:
- 闪购活动
- 品类日
- 大促活动
- 新人专享

**报名条件**:
- 店铺评分达标
- 商品符合要求
- 价格有竞争力
- 库存充足

### 7.3 联盟营销

**操作路径**: 营销 → 联盟营销

**设置步骤**:
```
1. 开通联盟营销
2. 设置佣金比例（建议 15-25%）
3. 添加商品到联盟
4. 等待达人申请
5. 审核通过
6. 达人带货
7. 成交后支付佣金
```

## 八、财务管理

### 8.1 账户余额

**查看路径**: 财务 → 账户余额

**余额构成**:
- 可提现余额
- 冻结金额（售后保证金）
- 待结算金额

### 8.2 提现操作

**操作路径**: 财务 → 提现

**提现步骤**:
```
1. 点击「申请提现」
2. 输入提现金额
3. 选择提现账户
4. 确认提现
5. 等待到账（1-3 个工作日）
```

### 8.3 账单明细

**查看路径**: 财务 → 账单明细

**账单类型**:
- 收入明细（订单结算）
- 支出明细（佣金、退款）
- 推广明细（广告投放）
