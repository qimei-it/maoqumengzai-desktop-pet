# TikTok 店铺入驻常见问题解答

## 一、资质准备

### Q1：个人可以入驻吗？

**答**：可以。TikTok Shop 支持个人和企业入驻。

| 类型 | 所需资质 | 适合人群 |
|------|---------|---------|
| 个人店铺 | 身份证 | 个人卖家、达人 |
| 企业店铺 | 营业执照 + 法人身份证 | 公司、品牌方 |

### Q2：营业执照有什么要求？

**答**：
- ✅ 营业执照状态正常（未注销、未异常）
- ✅ 经营范围包含所售商品类目
- ✅ 建议注册资金≥100 万（部分类目要求）
- ❌ 个体工商户入驻部分市场受限

### Q3：没有品牌可以入驻吗？

**答**：可以。

- **无品牌**: 选择"无品牌"选项，销售白牌商品
- **有品牌**: 提供商标注册证或品牌授权书

## 二、入驻流程

### Q4：入驻需要多长时间？

**答**：
```
注册账号：10-15 分钟
提交资料：30-60 分钟
审核时间：3-5 个工作日
─────────────────
总计：约 1 周
```

### Q5：审核被拒怎么办？

**答**：常见被拒原因及解决方案：

| 原因 | 解决方案 |
|------|---------|
| 资料不清晰 | 重新拍摄清晰照片 |
| 经营范围不符 | 更换营业执照或变更经营范围 |
| 类目选择错误 | 选择正确的经营类目 |
| 资料不完整 | 补充缺失的材料 |

### Q6：可以加急审核吗？

**答**：不支持加急。但可以通过以下方式提高通过率：
- 确保资料完整清晰
- 选择正确的类目
- 避免重复提交

## 三、保证金

### Q7：保证金是多少？

**答**：不同市场保证金不同：

| 市场 | 保证金 | 退还条件 |
|------|--------|---------|
| 美国 | $1500 | 关店后退还 |
| 英国 | £0（暂免） | - |
| 东南亚 | 各国不同 | 关店后退还 |

### Q8：保证金可以分期吗？

**答**：不可以，需要一次性缴纳。

### Q9：保证金什么时候退还？

**答**：满足以下条件可申请退还：
- 店铺关闭
- 无未完成的订单
- 无未处理的售后/纠纷
- 无违规扣款

退还时间：15-30 个工作日

## 四、店铺类型

### Q10：本土店和跨境店有什么区别？

**答**：

| 对比项 | 本土店 | 跨境店 |
|--------|--------|--------|
| 注册主体 | 当地公司/个人 | 中国公司 |
| 所需资质 | 当地营业执照 | 中国营业执照 |
| 物流方式 | 本地发货 | 跨境物流 |
| 流量扶持 | 有 | 较少 |
| 结算周期 | 较短 | 较长 |

### Q11：全托管模式是什么？

**答**：全托管是 TikTok 官方运营模式。

**商家负责**：
- 供货
- 发货到国内仓

**TikTok 负责**：
- 运营销售
- 跨境物流
- 售后服务

**适合**：有供应链优势，无运营能力的商家

### Q12：可以选择多个市场吗？

**答**：可以。但需要：
- 分别提交入驻申请
- 满足各市场的资质要求
- 缴纳各市场的保证金

## 五、收款结算

### Q13：支持哪些收款方式？

**答**：
- Payoneer（派安盈）
- WorldFirst（万里汇）
- LianLian（连连支付）
- PingPong

### Q14：结算周期是多久？

**答**：
- 订单确认收货后 8 天可提现
- 提款到账时间：1-3 个工作日

### Q15：收款账户必须是法人吗？

**答**：
- 企业店铺：建议与营业执照一致
- 个人店铺：可与身份证一致

## 六、类目选择

### Q16：如何选择经营类目？

**答**：
1. 根据营业执照经营范围
2. 根据供应链优势
3. 参考平台热销类目

**推荐新手类目**：
- 家居百货
- 美妆工具
- 服饰配饰
- 宠物用品

### Q17：一个店铺可以卖多个类目的商品吗？

**答**：可以。但有建议：
- 主营类目 1-2 个（流量更精准）
- 相关类目可搭配销售
- 特殊类目需要资质（如食品、化妆品）

### Q18：哪些类目需要特殊资质？

**答**：
| 类目 | 所需资质 |
|------|---------|
| 食品 | 食品经营许可证 |
| 化妆品 | 化妆品备案/许可证 |
| 3C 电子 | 3C 认证 |
| 母婴用品 | 产品质检报告 |
| 医疗器械 | 医疗器械经营许可证 |

## 七、违规处罚

### Q19：什么行为会被处罚？

**答**：
- 售假/侵权
- 虚假发货
- 延迟发货
- 售卖违禁品
- 刷单/虚假交易
- 诱导线下交易

### Q20：处罚有哪些类型？

**答**：
```
轻微违规
├─ 警告
├─ 商品下架
└─ 扣分

严重违规
├─ 限制流量
├─ 冻结资金
└─ 关闭店铺
```

### Q21：被处罚可以申诉吗？

**答**：可以。

**申诉流程**：
1. 收到处罚通知
2. 准备申诉材料
3. 在卖家中心提交申诉
4. 等待审核（3-5 个工作日）
5. 收到申诉结果

## 八、店铺运营

### Q22：新店如何快速起量？

**答**：
- 完善店铺信息（增加信任）
- 上架 10-20 款产品（丰富选择）
- 设置优惠券活动（吸引购买）
- 联系达人合作（增加曝光）
- 投放广告（快速引流）

### Q23：需要囤货吗？

**答**：看运营模式：
- **自发货模式**: 需要备货
- **全托管模式**: 发到国内仓即可
- **无货源模式**: 出单后采购（风险低）

### Q24：需要专门的运营团队吗？

**答**：看规模：
- **小规模**: 1-2 人可兼顾
- **中等规模**: 需要运营 + 客服 + 打包
- **大规模**: 需要完整团队
