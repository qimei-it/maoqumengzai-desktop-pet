# TikTok 店铺搭建指南

## 店铺类型选择

### 店铺类型对比
| 类型 | 门槛 | 费用 | 适合人群 |
|------|------|------|---------|
| 个人店 | 低 | 1%佣金 | 个人卖家 |
| 个体店 | 中 | 1%佣金 | 小商家 |
| 企业店 | 高 | 1%佣金+保证金 | 品牌/企业 |
| 旗舰店 | 高 | 1%佣金+保证金 | 品牌方 |

### 开店流程
```
1. 准备资料
├─ 营业执照
├─ 身份证
├─ 银行账户
└─ 品牌授权书(如需)

2. 提交审核
├─ 填写店铺信息
├─ 上传资料
└─ 等待审核(1-3天)

3. 店铺装修
├─ 上传店铺头像
├─ 设置店铺简介
└─ 装修店铺首页

4. 商品上架
├─ 准备商品图片
├─ 编写商品详情
└─ 设置价格库存
```

## 店铺基础设置

### 店铺信息
```
【店铺名称】
├─ 简洁易记
├─ 体现品类/特色
└─ 避免侵权词汇

【店铺简介】
├─ 核心卖点
├─ 服务承诺
└─ 联系方式

【店铺头像】
├─ Logo/品牌图
├─ 清晰可识别
└─ 正方形 1:1
```

### 运费模板
```
【按件计费】
├─ 首重1件: ¥X
├─ 每加1件: +¥Y
└─ 包邮设置

【按重量计费】
├─ 首重1kg: ¥X
├─ 续重每1kg: +¥Y
└─ 包邮设置

【包邮区域】
├─ 全国包邮
├─ 部分地区包邮
└─ 偏远地区除外
```

## 首批商品上架

### 商品分类
```
【引流款】
├─ 低价、高频
├─ 作用: 吸引流量
└─ 占比: 20-30%

【利润款】
├─ 中高价、高利润
├─ 作用: 主要盈利
└─ 占比: 50-60%

【形象款】
├─ 高价、高品质
├─ 作用: 品牌形象
└─ 占比: 10-20%
```

### 上架顺序
1. 先上架引流款，快速积累销量
2. 再上架利润款，开始盈利
3. 后上架形象款，提升品牌
