# TikTok Shop 英国区入驻要求

## 入驻条件

### 本土店（英国公司）

**必需材料**:
1. 英国公司注册证明 (Companies House)
2. 英国增值税号 (VAT Number)
3. 法人英国身份证/护照
4. 英国银行账户 (Sort Code + Account Number)
5. 英国联系电话
6. 英国发货仓库地址

**入驻难度**: ⭐⭐⭐ 较低

**保证金**: £0（暂免）

### 跨境店（中国公司）

**必需材料**:
1. 中国营业执照
2. 法人身份证
3. 跨境电商资质证明
4. 英国 VAT 税号
5. 海外仓证明或物流方案
6. 跨境收款账户

**入驻难度**: ⭐⭐⭐⭐ 中等

---

## 入驻流程

### 步骤 1: 在线注册
1. 访问 TikTok Shop Seller Center UK
2. 填写邮箱和公司信息
3. 验证手机号

### 步骤 2: 提交资料
1. 上传公司注册证明
2. 上传法人身份证明
3. 填写 VAT 信息
4. 绑定收款账户

### 步骤 3: 等待审核
审核时间：1-2 个工作日

### 步骤 4: 店铺开通
1. 审核通过收到通知
2. 完成店铺设置
3. 上架商品

---

## VAT 税务要求

### VAT 注册
- 年销售额超过 £85,000 必须注册 VAT
- 跨境卖家必须注册 VAT
- 仓库在英国必须注册 VAT

### VAT 申报
- 按季度申报
- 使用 Making Tax Digital (MTD) 系统
- 可委托会计师处理

### VAT 税率
| 类型 | 税率 |
|------|------|
| 标准税率 | 20% |
| 优惠税率 | 5% |
| 零税率 | 0% |

## 禁售商品

- 烟草产品
- 酒精饮料
- 药品
- 武器
- 成人用品
- 仿牌商品
